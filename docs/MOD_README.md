# PohSMP Core (`pohsmp_core`)

Основной мод сервера PohSMP. Нужен и на сервере, и у игроков (одна версия).
Вобрал в себя `pohsmp_camfix` — старый jar из сборки убрать.

## Что внутри
- **Камера в роликах** (только клиент): пока идёт ролик CNPCExtended, модель игрока видна от первого лица, рука скрыта.
  Конфиг клиента `config/pohsmp_core-client.toml`, раздел `[camera]`: `enabled`, `mode` (cnpcext/distance/both), `distanceThreshold`.
- **Помощники для скриптов CNPC**: `var Core = Java.type("ru.pohsmp.core.Api")`
  - `Core.version()` — версия мода;
  - `Core.cmd(world.getMCLevel(), "команда")` — тихая команда от сервера (без вывода в чат и лог), возвращает результат;
  - `Core.hide(сущность, тики)` / `Core.show(сущность)` / `Core.isHidden(сущность)` (1.12.1) — спрятать от всех игроков
    (см. «Скрытие сущностей»); сущность — `npc`, `player`, `e.target` из скрипта или сущность Minecraft; тики ≤ 0 — до `show`.
    Полная форма: `Core.hide(сущность, тики, безУрона, безСтолкновений[, наМесте])` (по умолчанию на месте держатся мобы/NPC, не игроки).
  - **Каст заклинаний NPC-магом** (1.12.0, `spell/NpcCast`) — см. раздел «NPC-маги» ниже.

## NPC-маги: `Core.cast`
NPC CustomNPCs (или любой моб, кроме игрока) кастует заклинание этого мода или Iron's так же, как игрок:
поворачивается к цели, проходит проверки самого заклинания (дальность, прямая видимость, свои условия),
дальше идут те же шаги Iron's, что у игрока: начало, тик каста, каст и завершение. Поэтому у NPC работают
эффекты, печати, ролик камеры (Низвержение, Млечный Путь и др.) и удержание цели (Дезинтеграция).
Анимация каста игрока (Iron's или своя, `pohsmp_*`) проигрывается на модели NPC у всех игроков рядом.
Маны и перезарядки у NPC нет, как у мобов Iron's.

| Вызов | Что делает |
|---|---|
| `Core.cast(npc, "pohsmp_core:disintegration", target)` | каст на максимальном уровне заклинания; `true`, если каст начался |
| `Core.cast(npc, id, target, level)` | то же с уровнем (обрезается до уровней заклинания; 0 — максимальный) |
| `Core.cast(npc, id, x, y, z[, level])`, `Core.castAt(npc, id, x, y, z[, level])` | каст в точку |
| `Core.cancelCast(npc)` | прервать каст; `false`, если NPC не кастует или заклинание неотменяемое |
| `Core.cancelCast(npc, true)`, `Core.forceCancelCast(npc)` | прервать любой каст (сброс босса, смена фазы) |
| `Core.isCasting(npc)` | идёт ли каст |
| `Core.castingSpell(npc)` | id заклинания в касте или `""` |

- `npc` — `e.npc` из события или любой `IEntity` (подойдёт и сущность Minecraft).
- `id` — `"pohsmp_core:…"` или `"irons_spellbooks:…"`; без префикса ищется сначала в этом моде, потом в Iron's.
- `target` бывает трёх видов. Существо: `IEntity`, например `e.npc.getAttackTarget()` или игрок. Точка: `IPos`
  (берётся центр блока), массив `[x, y, z]` или объект `{x:…, y:…, z:…}`. `null`: цель атаки NPC, а если её нет,
  то прямо по взгляду. Существо-цель NPC отслеживает весь каст, точка остаётся неподвижной.
- Почему каст не начался, видно в логе сервера: `[pohsmp_core] Core.cast …: причина`. Причины: цель вне дальности
  или не видна, NPC уже кастует, нет такого заклинания и т. п.
- Правила заклинаний действуют как у игрока:
  - долгий каст, который заклинание разрешает сбить, прерывается уроном по NPC;
  - неотменяемый каст (Дезинтеграция и др.) урон не сбивает, и `Core.cancelCast(npc)` его не прерывает,
    это может только `Core.cancelCast(npc, true)`;
  - если цель удержания пропала (умерла, ушла в другое измерение), заклинание само прерывает каст;
  - смерть или выгрузка NPC прерывает каст.
- Во время долгого каста NPC стоит на месте и смотрит на цель.
- В начале и в конце каста (успешном или прерванном) мод вызывает в скрипте NPC функции `cast_start(e)` и `cast_end(e)`,
  если они есть. Поля `e`: `npc`, `spell` (id; то же в `caster` для старых скриптов), `cancelled` (`true`, если каст прерван), `x`, `y`, `z`.
  У мгновенных заклинаний каст проходит сразу, поэтому функция вызывается ещё внутри `Core.cast`.
- Команды для проверки (оп 2): `/pohsmp npccast <кто> "<id>" [уровень] [entity <цель> | at <x y z>]`
  и `/pohsmp npccancel <кто> [true]`. Во втором аргументе id заклинания пишется в кавычках.

Пример: босс раз в 15 секунд кастует по цели Дезинтеграцию, а при 50% здоровья прерывает каст и переходит
ко второй фазе. Скрипт вешается на NPC во вкладку «Скрипты», язык ECMAScript.

```javascript
var Core = Java.type("ru.pohsmp.core.Api");
var phase2 = false;

function init(e) { e.npc.getTimers().forceStart(1, 300, true); }   // таймер 1: каждые 15 с

function timer(e) {
    if (e.id != 1 || Core.isCasting(e.npc)) return;
    var t = e.npc.getAttackTarget();
    if (t == null) return;
    if (!phase2) Core.cast(e.npc, "pohsmp_core:disintegration", t);
    else Core.cast(e.npc, "irons_spellbooks:fireball", t, 5);           // Iron's, уровень 5
}

function damaged(e) {
    if (phase2 || e.npc.getHealth() > e.npc.getMaxHealth() / 2) return;
    phase2 = true;
    Core.cancelCast(e.npc, true);                                      // Дезинтеграцию можно прервать только так
    Core.cast(e.npc, "pohsmp_core:singularity", e.npc.getX(), e.npc.getY() + 1, e.npc.getZ() + 6);  // в точку
}

function cast_end(e) {
    if (!e.cancelled) e.npc.say("§6" + e.spell + "!");
}
```

- **Школа Iron's «Божественная»** (`pohsmp_core:divine`, атрибуты `divine_spell_power` / `divine_magic_resist`, тип урона `divine_magic` сквозь броню).
- **Заклинание «Дезинтеграция»** (`pohsmp_core:disintegration`, уровень 1, каст 10 с, урон не сбивает): цель в 48 блоках
  застывает и поднимается на 0.75 блока, вокруг игрока и цели магические круги (рисует клиент, текстуры `tools/gen_fx_textures.ps1`),
  в конце вспышка и столб света, урон 50% макс. HP + 40 сквозь броню.
- **Ступени свитков** выше Легендарной: Высшая (алый), Мифическая (фиолетовый), Божественная (золотой) — подпись в подсказке свитка;
  у Божественной аура при касте и отдача после. Как задавать — `give_commands.txt`.
- **Школа «Высшая»** (1.3.0; `pohsmp_core:higher`, алая, атрибуты `higher_spell_power` / `higher_magic_resist`, тип урона `higher_magic`, броня учитывается,
  множитель `[higher] damageMult`). Шесть заклинаний уровня 1 со ступенью Высшая — по одному для магов второго дня и Эшли:
  Колыбель кошмара, Звезда судьбы, Сингулярность, Печать запрета, Вознесение ветра, Без пепла. Отрисовка — `client/HigherFx`
  (пакет `HFx`), текстуры — `tools/gen_higher_textures.ps1`. Свои эффекты: Кошмарный сон, Ужас, Печать запрета, Тяжесть, Вознесение.
- **Печати и эффекты из JSON** (1.11.0, `ru.pohsmp.core.fx`, формат — `docs/sigils.md`, `docs/fx.md`): печати `assets/pohsmp_core/sigils/`,
  эффекты `fx/`, стили школ `fx/styles/`, сгенерированные конструкции `fx/meshes/`. Рисует клиент (`client/fx`), сервер шлёт один пакет на экземпляр.
  Конфиг клиента, раздел `[fx]`: `maxDistance` (128), `maxInstances` (96), `quality` (high/low).
  Команды (оп 2): `/pohsmp sigil play <id> [масштаб] [ориентация]`, `/pohsmp sigil stop`, `/pohsmp fx play <id> [стиль]`, `/pohsmp mesh play <id> [секунды]`,
  `/pohsmp fx reload`. Из скриптов CNPC: `Core.sigil(level, id, x, y, z, '{"orientation":"ground","scale":1}')`, `Core.sigilStop(level, id, "")`,
  `Core.fx(level, id, x, y, z, yaw, стиль)`.
- **Скрытие сущностей** (1.12.1, `Hidden`, клиент `client/HiddenEntities`, пакет `HideMsg`): любую живую сущность — игрока, моба,
  NPC CustomNPCs — не видно никому: модель, броня, предметы в руках, имя, тень, огонь и контур свечения. Хитбокс F3+B остаётся.
  Сервер держит на ней ванильную невидимость (только флаг — без частиц и иконки), шлёт пакет всем, кто её видит, и каждому,
  кто начнёт видеть позже (подошёл, перезашёл, сменил измерение); срок истекает и на клиенте. По умолчанию без урона
  (и удары, и `/damage`), без столкновений (команда `pohsmp_hidden` с collisionRule never — только если у сущности нет своей команды;
  снаряды пролетают, ПКМ не срабатывает), мобы не выбирают её целью. Моб/NPC стоит на месте, где его спрятали; огонь гасится.
  Команды (оп 2): `/pohsmp hide <цели> [секунды]` (без секунд — до show), `/pohsmp show <цели>`.
  Ограничение: сущности с GeckoLib-рендером (не `LivingEntityRenderer`) событие `RenderLivingEvent` не шлют — их не прячет.
- **«Появление Ковена»** (1.11.0, Мифическая, школа Края, `pohsmp_core:coven_arrival`): первое использование отмечает арену (свиток цел),
  в 8 блоках от метки — переставляет её; метку видит только заклинатель. Шифт+ПКМ со свитком (или с выбранным в книге заклинанием) по существу —
  свита, до 2, снова — убрать. Издалека — каст 90 с, не сбивается: ролик для всех в 98 блоках от арены и от заклинателя (остальные ролики — 64),
  портал на арене, выход свиты (30 и 34 с) и заклинателя (38 с), реплика, ритуал (69 с), на 83 с — Закрытие Пространства над ареной на 15 мин.
  Перенос из другого измерения разрешён. Пока трое в портале, урон по ним отменяется.
  **События для скрипта NPC из свиты** (CustomNPCs): мод вызывает в скрипте NPC функции с этими именами, если они есть:
  ```javascript
  function coven_exit(e) { e.npc.say("...") }    // вышел из портала
  function coven_ritual(e) { }                   // начало ритуала: поза, анимация Epic Fight и т.п.
  ```
  Поля `e`: `npc` (как в обычных событиях), `type`, `caster` (имя заклинателя), `x`, `y`, `z`. Во время ролика NPC держится на своём месте.
  Без скрипта (1.11.2) мод сам: НПС кланяется на кивок заклинателя (анимация CNPC 11), выходит из портала шагами,
  на ритуале — руки вперёд (3), после ролика прежняя анимация. С 1.12.1 «внутри портала» свита и заклинатель
  стоят на арене сразу за порталом, спрятанные через «Скрытие сущностей» (раньше NPC поднимали на 150 блоков над ареной). С 1.11.3 свита в начале каста встаёт по бокам от заклинателя; на 11 с перед ним
  раскрывается свой портал, на 16–19 с он и свита идут в него вперёд, на 19 с портал схлопывается.
- **Вечная метель** (Высшая): с 1.11.0 без кругов — стена снега у края r12, иней на земле у стены, снег и белая дымка внутри (частицы — у каждого клиента).
- **Школа «Безмолвная», ступень «Неизвестная», Посох безмолвной ведьмы** (T18 — 1.12, T20 — 1.13.0): `pohsmp_core:silent`, бирюзовая,
  атрибуты `silent_spell_power` / `silent_magic_resist`, тип урона `silent_magic` сквозь броню. Посох `pohsmp_core:silent_witch_staff`
  (+25 % к силе Безмолвной магии, +10 % к силе магии, +25 % к восстановлению маны) держит пять заблокированных слотов
  (колесо Iron's, каст с руки): «Врата» (заглушка до T03) и четыре заклинания T20 — для них комплект одежды не нужен; свитков нет,
  без посоха в основной руке не кастуются. Ни звуков произнесения, ни реплик — только короткий хрустальный «дзынь» посоха.
  Числа — раздел `[silent_staff]` серверного конфига (каст, откат, мана, урон, радиусы); урон умножается на силу Безмолвной магии.
  - «Ветряные копья»: до 5 целей в конусе 60° на 32 блока (ближайшие к прицелу), копья над плечами 0.5 с, затем разом в голову — 14 урона, отброс 0.6.
  - «Безмолвный залп»: каст 3 с, 24 печати веером за спиной; в конце — стрела света из каждой во враждебных существ в радиусе 24 (по кругу, ≤ 6 в одного), 6 урона; игроков не бьёт никогда (как «Врата»).
  - «Барьер»: купол r5 на 8 с, идёт за заклинателем. Снаряды снаружи (ванильные и Iron's) гаснут на поверхности; лучи, касания и прочий
    прямой урон заклинаниями из-за купола по заклинателю и его союзникам внутри отменяются. Ближний бой и проход сквозь купол свободны.
  - «Чёрное пламя Ворганы»: каст 2 с (тень дракона над правым плечом), выдох 3 с конусом 40° на 12 блоков: 3 урона раз в 10 тиков +
    эффект «Чёрное пламя» 8 с, 1.5 урона/с — не огонь: вода не тушит, молоко не снимает.
  Эффекты `fx/silent_wind_spears.json`, `silent_volley.json`, `silent_barrier_dome.json`, `silent_worgan_flame.json` (чат идей) подхватываются
  сами, когда появятся; до того — заглушки из частиц. Модель посоха — `tools/gen_silent_staff.py`.
- **Вкладка в творческом** «PohSMP» (иконка `irons_spellbooks:gold_crown`).
- Настройки сервера: `world/serverconfig/pohsmp_core-server.toml`.

## Сборка
Для компиляции нужны jar из `libs/README.md` (Iron's, GeckoLib, PlayerAnimator). Анимация каста на модели NPC
делается миксином `mixin/HumanoidModelMixin` (`pohsmp_core.mixins.json`, только клиент).

Iron's и GeckoLib для компиляции лежат в `C:\Users\xeone\pohcore-build\libs` (копии из модов Prism, `compileOnly fg.deobf`).

Исходник здесь, собирается в `C:\Users\xeone\pohcore-build` (вне OneDrive): скопировать `src`, `gradle.properties`, `build.gradle`,
затем `gradlew build` с `JAVA_HOME` = `%APPDATA%\PrismLauncher\java\java-runtime-delta` (JDK 21; JDK 17 для компиляции Gradle скачивает сам). Готовый jar — `build\libs`, копия лежит здесь.
При каждом изменении поднимать `mod_version` в `gradle.properties`.
