# PohSMP Core (`pohsmp_core`)

Основной мод сервера PohSMP. Нужен и на сервере, и у игроков (одна версия).
Вобрал в себя `pohsmp_camfix` — старый jar из сборки убрать.

## Что внутри
- **Камера в роликах** (только клиент): пока идёт ролик CNPCExtended, модель игрока видна от первого лица, рука скрыта.
  Конфиг клиента `config/pohsmp_core-client.toml`, раздел `[camera]`: `enabled`, `mode` (cnpcext/distance/both), `distanceThreshold`.
- **Помощники для скриптов CNPC**: `var Core = Java.type("ru.pohsmp.core.Api")`
  - `Core.version()` — версия мода;
  - `Core.cmd(world.getMCLevel(), "команда")` — тихая команда от сервера (без вывода в чат и лог), возвращает результат.

- **Школа Iron's «Божественная»** (`pohsmp_core:divine`, атрибуты `divine_spell_power` / `divine_magic_resist`, тип урона `divine_magic` сквозь броню).
- **Заклинание «Дезинтеграция»** (`pohsmp_core:disintegration`, уровень 1, каст 10 с, урон не сбивает): цель в 48 блоках
  застывает и поднимается на 0.75 блока, вокруг игрока и цели магические круги (рисует клиент, текстуры `tools/gen_fx_textures.ps1`),
  в конце вспышка и столб света, урон 50% макс. HP + 40 сквозь броню.
- **Ступени свитков** выше Легендарной: Высшая (алый), Мифическая (фиолетовый), Божественная (золотой) — подпись в подсказке свитка;
  у Божественной аура при касте и отдача после. Как задавать — `give_commands.txt`.
- **Школа «Высшая»** (1.3.0; `pohsmp_core:higher`, алая, атрибуты `higher_spell_power` / `higher_magic_resist`, тип урона `higher_magic`, броня учитывается,
  множитель `[higher] damageMult`). Шесть заклинаний уровня 1 со ступенью Высшая — по одному для магов второго дня и Эшли:
  Колыбель кошмара, Звезда судьбы, Сингулярность, Печать запрета, Вознесение ветра, Без пепла. Отрисовка — `client/HigherFx`
  (пакет `HFx`), текстуры — `tools/gen_higher_textures.ps1`. Свои эффекты: Кошмарный сон, Ужас, Печать запрета, Тяжесть, Вознесение.
- **Печати и эффекты из JSON** (1.11.0, `ru.pohsmp.core.fx`, формат — `docs/sigils.md`, `docs/fx.md`): печати `assets/pohsmp_core/sigils/`,
  эффекты `fx/`, стили школ `fx/styles/`, сгенерированные конструкции `fx/meshes/`. Рисует клиент (`client/fx`), сервер шлёт один пакет на экземпляр.
  Конфиг клиента, раздел `[fx]`: `maxDistance` (128), `maxInstances` (96), `quality` (high/low).
  Команды (оп 2): `/pohsmp sigil play <id> [масштаб] [ориентация]`, `/pohsmp sigil stop`, `/pohsmp fx play <id> [стиль]`, `/pohsmp mesh play <id> [секунды]`,
  `/pohsmp fx reload`. Из скриптов CNPC: `Core.sigil(level, id, x, y, z, '{"orientation":"ground","scale":1}')`, `Core.sigilStop(level, id, "")`,
  `Core.fx(level, id, x, y, z, yaw, стиль)`.
- **«Появление Ковена»** (1.11.0, Мифическая, школа Края, `pohsmp_core:coven_arrival`): первое использование отмечает арену (свиток цел),
  в 8 блоках от метки — переставляет её; метку видит только заклинатель. Шифт+ПКМ со свитком (или с выбранным в книге заклинанием) по существу —
  свита, до 2, снова — убрать. Издалека — каст 90 с, не сбивается: ролик для всех в 98 блоках от арены и от заклинателя (остальные ролики — 64),
  портал на арене, выход свиты (30 и 34 с) и заклинателя (38 с), реплика, ритуал (69 с), на 83 с — Закрытие Пространства над ареной на 15 мин.
  Перенос из другого измерения разрешён. Пока трое в портале, урон по ним отменяется.
  **События для скрипта NPC из свиты** (CustomNPCs): мод вызывает в скрипте NPC функции с этими именами, если они есть:
  ```javascript
  function coven_exit(e) { e.npc.say("...") }    // вышел из портала
  function coven_ritual(e) { }                   // начало ритуала: поза, анимация Epic Fight и т.п.
  ```
  Поля `e`: `npc` (как в обычных событиях), `type`, `caster` (имя заклинателя), `x`, `y`, `z`. Во время ролика NPC держится на своём месте.
  Без скрипта (1.11.2) мод сам: НПС кланяется на кивок заклинателя (анимация CNPC 11), выходит из портала шагами,
  на ритуале — руки вперёд (3), после ролика прежняя анимация. НПС «внутри портала» ждёт в 150 блоках над ареной
  (рисовалка CNPC не учитывает невидимость). С 1.11.3 свита в начале каста встаёт по бокам от заклинателя; на 11 с перед ним
  раскрывается свой портал, на 16–19 с он и свита идут в него вперёд, на 19 с портал схлопывается.
- **Вечная метель** (Высшая): с 1.11.0 без кругов — стена снега у края r12, иней на земле у стены, снег и белая дымка внутри (частицы — у каждого клиента).
- **Вкладка в творческом** «PohSMP» (иконка `irons_spellbooks:gold_crown`).
- Настройки сервера: `world/serverconfig/pohsmp_core-server.toml`.

## Сборка
Iron's и GeckoLib для компиляции лежат в `C:\Users\xeone\pohcore-build\libs` (копии из модов Prism, `compileOnly fg.deobf`).

Исходник здесь, собирается в `C:\Users\xeone\pohcore-build` (вне OneDrive): скопировать `src`, `gradle.properties`, `build.gradle`,
затем `gradlew build` с `JAVA_HOME` = `%APPDATA%\PrismLauncher\java\java-runtime-delta` (JDK 21; JDK 17 для компиляции Gradle скачивает сам). Готовый jar — `build\libs`, копия лежит здесь.
При каждом изменении поднимать `mod_version` в `gradle.properties`.
