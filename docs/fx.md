# Эффекты: формат JSON (черновик)

Черновик схемы для общей системы эффектов из [`specs/fx_spec.md`](specs/fx_spec.md). Печати — один из её элементов,
их формат описан в [`sigils.md`](sigils.md). Готовые данные: стили школ (`assets/pohsmp_core/fx/styles/`),
спрайты частиц (`assets/pohsmp_core/textures/fx/`, генератор `tools/gen_sigil_textures.py`),
демо-эффекты `assets/pohsmp_core/fx/light_rain.json`, `scarlet_slash.json`, `deep_pulse.json`. Отрисовщик — `ru.pohsmp.core.client.fx`.

Время — в **тиках**, углы — в **градусах**, размеры — в **блоках**.

## Эффект

```json
{
  "style": "divine",
  "duration": 200,
  "elements": [
    { "type": "sigil", "id": "silent_gate_sky", "delay": 0, "at": "caster+0,9,0" },
    { "type": "beam_rain", "delay": 40, "duration": 120, "area": 12, "count": 30, "color": "@primary" }
  ]
}
```

| Поле | Что это |
|---|---|
| `style` | стиль школы по умолчанию (`styles/<имя>.json`); при вызове можно подменить |
| `duration` | общая длина эффекта; `-1` — пока его не остановят (для канальных заклинаний) |
| `elements` | элементы на общей временной шкале |

Вызов из Java: `Fx.play(level, "light_rain", ctx)`, где `ctx` — кастер, цель, точки, направление, масштаб, seed. Возвращает id экземпляра:
его можно остановить (`Fx.stop`) или обновить (`Fx.update`) для канальных заклинаний.

## Общие поля элемента

| Поле | Что это |
|---|---|
| `type` | тип элемента (таблица ниже) |
| `delay`, `duration` | когда начинается и сколько длится (тики от старта эффекта) |
| `at` | привязка: `caster`, `target`, `point:<имя>` (точка из ctx), `caster.hand` (правая рука кастера), `caster.eyes`, `look:<дальность>` (точка взгляда); можно добавить смещение `+x,y,z` в осях взгляда кастера (x — вправо, y — вверх, z — вперёд) |
| `to` | вторая точка для элементов «между двумя точками» (`beam`, `lightning`, `chains`) |
| `travel` | элемент летит вперёд (по yaw эффекта, горизонтально) на столько блоков за свою `duration` (не для `sigil`/`mesh`) |
| `follow` | `true` — элемент следует за точкой привязки (иначе остаётся там, где появился) |
| `color` | цвет: `#RRGGBB` или ссылка на палитру стиля: `@primary`, `@secondary`, `@core`, `@shadow` |
| `brightness` | множитель яркости |
| `in`, `out` | плавность появления и исчезновения: `{ "duration": 6, "easing": "easeOutCubic" }` |
| `scale` | множитель размера элемента |
| `seed` | фиксированный seed случайностей (иначе берётся из ctx) — все игроки видят одно и то же |

Цвет `@…` берётся из палитры стиля, поэтому один эффект перекрашивается под школу заменой `style`.

## Стиль школы

```json
{
  "palette": { "primary": "#FFD36B", "secondary": "#FFF4D6", "core": "#FFFFFF", "shadow": "#8A6420" },
  "textures": { "sparks": "spark_soft", "runes": "rune_band", "shards": "feather", "sigil": "core" },
  "blend": "additive",
  "motion": { "rotationScale": 0.6, "jitter": 0.0, "easing": "easeOutSine" }
}
```

- `textures` — текстуры по умолчанию: элемент может написать `"texture": "@shards"` и получить перья у Божественной и осколки у Высшей.
- `blend` — `additive` (свет) или `translucent` (дым, тени).
- `motion` — характер движения: `rotationScale` умножает скорости вращения, `jitter` — рваность (0 — плавно, 1 — резко),
  `easing` — плавность по умолчанию, `pulse` — пульсация по умолчанию.

Готовые стили: `divine` (Божественная), `higher` (Высшая), `sculk` (Скалк), `coven` (Ковен), `forbidden` (Запретная).
Стили школ Iron's (T06, генератор `tools/gen_school_themes.py`): `fire`, `ice`, `lightning`, `nature`, `holy`, `school_blood`, `ender`,
`eldritch`, `evocation`, `wind` — у каждой свои частицы `@shards` (`mote_flame`, `mote_ice`, `mote_bolt`, `mote_leaf`, `mote_feather`,
`mote_drop`, `mote_ender`, `mote_eye`, `mote_rune`, `mote_wisp` в `textures/sigil/`), `@sigil` = `<школа>_seal`, `@runes` = `school_<школа>_band`
и характер движения (молния — быстро и рвано, природа и свет — плавно и медленно, кровь — пульс сердца). Подробно — `docs/sigils.md`, «Темы школ».

## Типы элементов

Каждая линия рисуется в 2 слоя: широкий мягкий ореол цвета элемента + узкое горячее ядро, подбелённое к белому.
Параметры с пометкой *(доп.)* добавлены при написании отрисовщика; без них элемент выглядит как раньше.

| type | Ключевые параметры |
|---|---|
| `sigil` | `id` печати, `orientation`, `scale` — см. [`sigils.md`](sigils.md) |
| `beam` | `at` → `to` (или `fromSky`: высота), `width`, `core` (доля ширины яркого ядра), `taper` (сужение к концу), `scroll` (бегущие по лучу сгустки света: длин луча в секунду, минус — обратно), `grow` (тики роста от начала к концу), `easing` (плавность роста, по умолчанию `easeOutCubic`; `easeInCubic` — падение с ускорением), `tail` (доля пути за концом, которая видна: шлейф падающей звезды, сужается и гаснет к хвосту), `head` (множитель свечения на конце), `flicker` |
| `beam_rain` | `area` (радиус), `count`, `interval` (тики между лучами), `width`, `height`, `impact` (id печати на месте удара; без него — вспышка и расходящееся кольцо) |
| `wave` | `shape`: `ring` (по земле) или `sphere` (пузырь с бликом); `radius`, `thickness` (ширина мягкой полосы за фронтом, по умолчанию 0.12·radius), `followTerrain` (полоса ложится на блоки), `rim` (яркость края сферы); *(доп.)* `texture` + `spin` (°/тик) — рисунок, растущий вместе с кольцом (например `sound_ring`) |
| `flash` | `size`, `anamorphic` (длина горизонтального блика), `rays` (число лучиков), `screen` (засветка экрана у кастера: сила 0–1); *(доп.)* `ring: true` — расходящееся кольцо |
| `trail` / `ribbon` | `width`, `length` (тики памяти), `fade` (степень угасания к хвосту, 1 — линейно). `trail` — светящийся след, всегда повёрнут к камере, с яркой головой (*(доп.)* `head`: размер головы в ширинах, 0 — без неё); `ribbon` — плоская лента, ширина по вертикали (щупальца), *(доп.)* `texture`. Точка следа — `at` в каждом кадре. *(доп.)* `orbit`: `{ radius, speed (°/тик), rise (качание вверх-вниз), risePeriod, climb (подъём, блоков за секунду) }` — точка кружит вокруг `at`, `count` таких следов равномерно по кругу. `trail` с `shape: "slash"` — серп мифических/Высших эффектов: `radius`, `arc` (°), `thickness`, `bend`, `secondary` (0–1), `sweep` (тики пролёта), `tail` (доля дуги за головой), `roll` (°), `rollAlt` (чередовать по seed), `reverse`, `pitch`, `yaw`; середина дуги в `at`, плоскость по взгляду |
| `slash` | дуга-разрез перед кастером в плоскости его взгляда: `radius`, `arc` (°), `thickness`, `bend` (0 — прямой отрезок, 1 — дуга окружности, больше — глубже), `secondary` (яркость тонкой второй дуги, `false`/0 — без неё). *(доп.)* `grow` (тики, за которые голова пробегает дугу, по умолчанию 4), `life` (тики жизни одного разреза, 10), `tilt` (° наклона плоскости: 0 — горизонтальный взмах, 90 — вертикальный), `pitch` (° наклона вверх/вниз), `dir` (1 / −1 — направление взмаха), серия: `count`, `interval` (тики), `tiltStep` (прибавка наклона; без него наклоны случайные по seed в ±70°), `alternate` (чередовать направление, по умолчанию да) |
| `sprites` | `texture` (`@shards`, `feather`…), `count`, `rate`, `spread` (шар разлёта) или `area` (диск на земле), `speed`, `gravity` (минус — всплывают), `spin`, `tumble`, `sway` (покачивание при падении — для перьев), `size` (`[от, до]` по времени), `life`; *(доп.)* `glow` — мягкий ореол за каждым спрайтом (0–1); `cone` (° полного угла) — частицы летят конусом по взгляду заклинателя (у экземпляра без заклинателя — по его yaw/pitch из `Fx.move`); `blend` (`additive`/`translucent`; без него тёмные цвета рисуются `translucent` — чёрное пламя, дым) |
| `lightning` | `at` → `to` (или `fromSky`: высота), `branches`, `jaggedness` (боковой разброс, доля длины куска), `regen` (перегенерация формы каждые N тиков), `width`; *(доп.)* `count` (сколько молний одновременно), `detail` (дроблений, 2^detail кусков; по умолчанию 5) |
| `vortex` | `radius` (вверху), `height` (0 — плоский водоворот), `arms`, `speed` (°/тик, × `rotationScale` стиля), `pull` (к центру, минус — выброс), `texture` (частиц); *(доп.)* `funnel` (радиус внизу как доля `radius`, 0.35), `turns` (витков на высоту, 1.25), `width` (лент), `particles`, `life`, `size` |
| `chains` | `at` → `to`, `link` (размер звена), `sag` (провис посередине), `tension` (0–1: натяжение убирает провис и даёт дрожь); *(доп.)* `grow` (тики, за которые цепь вытягивается от `at` к `to`; свежие звенья вспыхивают), `rattle` (амплитуда дрожи) |
| `aura` | `target` (`caster` / `target`; по умолчанию по `at`), `thickness`, `pulse` (период в тиках, или `[сила, период]`, или `{ amp, period }`); оболочка по росту сущности, кольцо под ногами (*(доп.)* `ring: false` — без него), *(доп.)* `motes` (искры вверх, 12), `texture` искр |
| `decal` | `texture` (трещины `slash_crack`/`higher_cracks`, выжженный след…), `radius`, `fadeOut` (тики); *(доп.)* `grow` (тики роста радиуса), `rotation` (°), `spin` (°/тик), `glow` (подсветка под рисунком, 0.2), `pulse` (период пульсации). Свежий рисунок первые 20 тиков раскалён добела. `shape: "crack"` — рисованная трещина поперёк взгляда: `length`, `width`, `grow` (тики раскрытия от середины), `branches`, `pulse` (0–1), `yaw`; `blend: "translucent"` — тёмное пятно (кратер) без свечения; `lift` (подъём над землёй против мерцания) |
| `wings` / `halo` | `size`, `flap` (амплитуда и период взмаха: `[°, тики]` или `{ amp, period }`; у `halo` — покачивание в блоках), `offset` (`"x,y,z"` или `[x, y, z]` в осях взгляда от `at`; по умолчанию крылья — за спиной на высоте лопаток, нимб — над головой). *(доп.)* `wings`: `spread` (° отвода крыльев назад, 25), `texture` (`wing`); `halo`: `tilt` (°, 12), `spin` (°/тик), `texture` (`thin_ring`) |
| `curtain` | завеса из вертикальных лучей: `count`, `radius` (или кольцо `[от, до]`), `height`, `grow`, `width` и `brightness` — число или `[от, до]`, `texture` (`beam_fade` гаснет кверху), `fromTop` (растут сверху вниз), `flicker` |
| `column` | сплошной столб: `radius`, `height`, ядро ярче краёв; кольца неподвижные на `ringHeights` или скользящие (`rings`, `ringSpeed`); `fill` |
| `tint` | цвет мира у игроков в `radius`: `color`, `strength`, плавные `in`/`out` (пост-эффект, без шейдерпаков) |
| `mesh` | `model` (сгенерированная модель), `appear`: `grow`, `fall` (с неба), `rise`; `break` (разлом на осколки). С `follow: true` модель едет за точкой привязки каждый кадр; у экземпляра без заклинателя, который сервер двигает `Fx.move(…, yaw, pitch)`, модель поворачивается по yaw и наклоняется по pitch (копьё смотрит по полёту) |

Текстуры элементов (`textures/fx/`, генератор `tools/gen_fx_elements.ps1`): `strip_soft` (профиль лент, молний, разрезов),
`chain_link`, `wing` (шарнир в uv 0.06, 0.59), `aura_shell`, `sound_ring` (звуковое кольцо), `slash_crack` (трещины).

Демо: `light_rain` (Божественная), `scarlet_slash` (Высшая: серия разрезов, осколки, трещины), `deep_pulse` (Скалк: звуковые кольца,
ленты, воронка, огоньки) — `/pohsmp fx play <id> [стиль]`.

## Код (готово в чате идей)

Чистая логика без Minecraft — пакет `ru.pohsmp.core.fx` (тесты `src/test/java/ru/pohsmp/core/fx/FxTest.java`, `gradlew test`):

- `FxDef` — эффект и его элементы из JSON; параметры типа элемента лежат сырым JSON (`Element.params`, `num`/`str`).
  `FxDef.Anchor` — разбор привязки (`caster+0,9,0`, `point:rift`, `look:24`…) и её точка в мире через `FxDef.Context`.
- `FxStyle` — стиль школы: `color("@primary")`, `texture("@shards")`, режим смешивания, характер движения.
- `FxMath` — оси взгляда (`forward`, `right`, `offset`), расстановка дочерних печатей дугой (`arc`),
  точки ударов ливня лучей с общим seed (`beamRain`) — у всех игроков одинаковые.
- `FxShapes` — формы линейных элементов: молния (`lightning`), дуга и тайминг разреза (`slashArc`, `slashSpan`), провис цепи (`chain`),
  спираль воронки (`spiral`, `pull`), взмах, пульс и огибающая вспышки (тесты `FxShapesTest`).
- `FxTrail` — память движущейся точки для `trail`/`ribbon`.
- `FxDef.TYPES` — список типов, которые рисует клиент (тест сверяет его с таблицей выше).

Клиент (`ru.pohsmp.core.client.fx`): `ElementDraw` (печати, mesh, flash, wave, beam, beam_rain, sprites, curtain, column, tint, decal),
`LineDraw` (trail, ribbon, slash, lightning, vortex, chains), `BodyDraw` (aura, wings, halo), примитивы — `FxDraw`.

Сеть (`net/FxMsg`) передаёт клиентам `Context` (позиции, yaw, seed): все игроки видят одно и то же.

## Объёмные структуры (`mesh`)

Структуры генерируются скриптами и описываются **частями**, а не полигонами: отрисовщик сам строит геометрию.
Пример — портал Ковена `assets/pohsmp_core/fx/meshes/coven_portal.json` (генератор `tools/gen_coven_portal.py`,
сцена «Портал Ковена» в `tools/sigil_preview.html`).

| Часть | Что это |
|---|---|
| `seed` | исходный многогранник в центре (`shape`, `radius`, `spin` по осям), исчезает по `vanish` |
| `ring` | кольцо-трубка (`radius`, `thickness`); при появлении поворачивается вокруг `tiltAxis` на `tiltTurns`° и ложится в плоскость, потом крутится `spin` °/с |
| `polygon` | рама-многоугольник из брусков (`sides`, `radius`, `rotation`, `thickness`, `spin`) |
| `facet` | треугольная грань: летит из `from` (грань семени) в `to` (место на раме), крутясь на `spinOnFly`° |
| `disc` | диск с текстурой (`texture`, `radius`, `blend`: `translucent` для тёмного космоса) |
| `boxes` | **объёмная модель из брусков** (врата «Безмолвной ведьмы», T03): `boxes` — список `[x0, y0, z0, x1, y1, z1, тон]` в блоках, необязательный 8-й элемент — поворот `[rx, ry, rz]` в градусах вокруг центра бруска (порядок применения: сначала `rz`, затем `rx` — наклон, затем `ry` — направление; как Euler «YXZ» в three.js: R = Ry·Rx·Rz); `tones` — цвета тонов (`#RRGGBB` или ссылки стиля `@primary`…), `glowTones` — номера тонов, которые рисуются аддитивно и светятся (полная яркость); остальные — `blend: translucent` с `opacity` и **затенением граней по нормали** (`shade: true`: верх ×1.0, бока ×0.82 / ×0.7, низ ×0.55), иначе объём не читается. Появление `appear.reveal: "down"` (или `"up"` — снизу вверх, рост из земли, ледяная гора `silent_crystal`): фронт идёт сверху вниз от `bounds[1]` до `bounds[0]` за `appear.duration`, брусок проявляется, когда фронт прошёл его центр (полоса `front` блоков — прозрачность 0→1 и белая вспышка-подсветка у фронта); разборка — общая `collapse` сущности. Генератор врат — `tools/gen_silent_gate.py` (~1400 брусков: рисовать одним буфером, без пересчёта каждый кадр) |

Плоскость структуры — XY, центр на высоте `center` над точкой привязки. `formedAt` — когда структура собрана,
`collapse` — сжатие в точку при остановке. Цвета — ссылки на палитру стиля (`style`).

**Удар по структуре (`hit`, T08).** У файла структуры может быть блок `hit` — те же поля, что у печати (docs/sigils.md, «Отклик на удар»).
Тогда `Fx.hit(level, inst, точка, сила)` по экземпляру (или по эффекту, в котором есть эта структура) даёт рябь: брускам `boxes`
добавляется яркость волны `SigilHit.wave`, где расстояние — **угол** между направлениями из центра на брусок и на точку удара (структура
считается сферой радиуса 1), `span = π`; светящиеся тона ярче в `1 + 1.5·волна` раз, остальные — в `1 + 5·волна` (стекло купола
вспыхивает), цвет уходит к белому на `min(0.8, 0.5·волна)`. Плюс вздрагивание масштаба (`shake`), вспышка и искры в точке удара по нормали
сферы. Включено у купола Барьера `silent_dome` (T20): `SageBarrierSpell.ripple` зовёт `Fx.hit` вместо частиц-заглушки. Превью —
сцена «Отклик на урон: купол Барьера»; код — `client/fx/MeshDraw` (`Run.hit`, `boxes`, `domeHits`).

## Как добавить эффект

1. Если нужен новый спрайт — добавить функцию в `tools/gen_sigil_textures.py` (раздел спрайтов) и запустить его.
2. Создать `assets/pohsmp_core/fx/<id>.json` по этой схеме, цвета — ссылками на палитру `@…`.
3. В игре: `/pohsmp fx reload`, `/pohsmp fx play <id> [стиль]` — проверить со стилями разных школ.

### Добавлено 19.11 («Безмолвные врата»)
- `mesh`: *(доп.)* `move: { from: [x, y, z], scaleFrom, delay, duration, easing }` — модель выходит из точки `at + from` (оси взгляда заклинателя:
  x вправо, y вверх, z вперёд) и масштаба `scaleFrom` к своему месту и размеру; `hinge: { pivot: [x, y, z], axis: "y", angle, delay, duration, easing }` —
  поворот всей модели вокруг оси через `pivot` (координаты модели, до `scale`) на `angle`° (створки ворот). Отсчёт `delay` — от начала элемента.
- `vortex`: *(доп.)* `to` — анкор широкого конца воронки (ось из `at` в `to`; без него — вверх на `height`), `flow: -1` — частицы текут к вершине (`at`).
- `beam_rain`: *(доп.)* `ground: true` — низ луча и `impact` на поверхности под каждой точкой (а не на высоте `at`).
- `mesh.hinge`: *(доп., 19.11)* `keys: [[тик, угол°, плавность], …]` — поворот на петле по ключам (тик от начала элемента, плавность — к этому
  ключу, по умолчанию `easeInOutSine`); до первого ключа — его угол, после последнего — последний. Без `keys` — `angle/delay/duration/easing`.

### Добавлено 19.11 (T22 «Небесная бабочка», нужно от кода)
Генератор — `tools/gen_celestial_butterfly.py`, письмо — `docs/inbox/2026-11-19_mgr_T22_celestial_visuals.md`.
- `mesh`, часть **`quad`** — текстурная плоскость (крыло): `texture`, `blend` (`translucent` / `additive`), `opacity`, `doubleSided` (рисовать
  обе стороны — крылья видны снизу), `corners` — 4 вершины в координатах модели в порядке uv (0,0) → (1,0) → (1,1) → (0,1) (v вниз, как в PNG);
  `hinge: { origin: [x,y,z], axis: [x,y,z], keys: [[тик, угол°, плавность], …] }` — поворот плоскости вокруг оси через `origin` по ключам
  (та же интерполяция, что `MeshDraw.hingeKeys`, тик — от начала элемента); `pulse: [сила, период]` — пульс яркости. Без поддержки части
  просто не видно (тело-`boxes` рисуется).
- `mesh.move.keys`: `[[тик, [x, y, z], плавность], …]` — смещение модели по ключам (в тех же единицах, что `from`: оси модели × `scale`),
  поверх `from`/`scaleFrom` (масштаб по-прежнему из `delay/duration/easing`). Острова парят и опускаются, тело бабочки подскакивает на взмахе.
  Без поддержки — работает обычный `move` (остров поднимается один раз и висит).
- `sprites`: `wrap: R` — частицы стоят в мире (не едут за `at`), но каждая заворачивается в куб ±R вокруг текущего `at` (бесконечное поле
  пыльцы вокруг идущей жертвы); `avoid: { radius, push }` — частицы в `radius` от кастера (центр на высоте 1) отодвигаются по горизонтали
  на `push·(1 − d/radius)` (лепестки расступаются); `path: [анкор, …]` + `width` — частица летит по кривой Catmull-Rom через анкоры за свою
  `life` (u = age/life), с поперечным разбросом `width·(1 − 0.75u)` (река бабочек). Без `path` — обычный разлёт (всплывают у первой точки).
