# Кодинг → управляющему, 19.11: T22 «Иллюзии» — что реально из «неотличимы»

Проверено по составу модов «POH SMP TEST» и тест-сервера. Там стоят Jade 11.13.2, JourneyMap 5.10.3 (и на клиенте, и на сервере), Epic Fight, Emotecraft, Oculus, FTB Teams и **Simple Voice Chat**. Это план, кода пока нет.

## Основа: копия — настоящий «клиентский игрок»
- **Как устроена копия.** У пострадавшего в клиентском мире появляется сущность класса `RemotePlayer` с отрицательным id. Профиль, скин, броня, предмет в руках и косметическая броня копируются с заклинателя.
- **Что получаем даром.** Копию рисует тот же рендер игрока, поэтому сами получаются ник над головой, тень, шейдерная тень Oculus, свечение (glowing), стрелы в теле и хитбокс.
- **Кто ведёт копию.** Положение и поведение копий считает сервер, а шлёт их только пострадавшим. Поэтому сервер знает хитбокс каждой копии и сам решает, попал ли по ней удар.
- **Союзники.** Определяю через FTB Teams. Союзники заклинателя иллюзий не видят.

## Пункт «неотличимы» по частям
| Что | Реально? | Как |
|---|---|---|
| Скин, броня, предмет, ник, тень, glowing | да | это настоящий рендер игрока |
| **Анимации Epic Fight** | да, но это главный риск | Все игроки на сервере анимируются через Epic Fight, и копия с ванильной анимацией выдаст себя сразу. Буду проигрывать EF-анимации (бег, замах) прямо на клиентском «патче» копии. Это нужно сначала проверить на практике. |
| Касты Iron's у копий | частично | Анимация каста и круги — да. Настоящего снаряда нет: копия «кастует», но фаербол не вылетает. Предлагаю запускать чисто визуальный снаряд, который гаснет через 1–2 с, без урона. |
| Шаги копий | да | Шаги чужих игроков присылает сервер. Для копий клиент сам играет звук шагов по блоку под ногами, с тем же шагом, что у бегущего игрока. |
| Удар по копии, анимация и звук урона | да | Сервер ловит атаку пострадавшего (ванильную и EF) и проверяет её по хитбоксу копии. Клиенту уходит «копия ранена»: покраснение, звук `player.hurt`, отброс. Копия держит 2–3 удара. |
| Стрелы и снаряды пострадавшего по копии | да | Сервер проверяет, пересекает ли снаряд копию, гасит его и проигрывает попадание. Чужие снаряды пролетают сквозь копию, но этого не видит никто, кроме пострадавшего. |
| Jade | да | Копия — обычная сущность-игрок, Jade покажет её как игрока. Чтобы скрытый настоящий игрок не «подсвечивался» в Jade, его надо выкинуть из рейтрейса Jade через его API (нужен Jade jar только для сборки, в моды ничего не ставлю). |
| JourneyMap | скорее всего да, но надо проверить | На радаре точки игроков берутся из клиентского мира, так что копия должна появиться сама. Скрыть настоящего игрока сложнее, потому что JM стоит и на сервере и может присылать позиции игроков отдельно. Посмотрю его API и конфиг сервера; если не выйдет, скрытие на миникарте упрощается до «точка остаётся». |
| F3: счётчик сущностей | да, само | Копия видна, значит считается, а скрытый игрок не рисуется и не считается — как у настоящего игрока за стеной. |
| F3+B (хитбоксы) | да | У копии хитбокс игрока. Хитбокс скрытого игрока тоже прячу. |
| Скрытие настоящего игрока | да | Пропускаю у пострадавшего рендер модели, тени, ника, частиц бега и эффектов (миксин; миксины в моде уже есть). |
| Звуки скрытого игрока | частично | Шаги и удары скрытого игрока сервер рассылает всем сразу, выборочно отменить нельзя. Клиент пострадавшего будет глушить звуки в точке скрытого игрока, но звуки, которые идут без привязки к сущности, могут проскочить. |

## Что нельзя скрыть — нужно согласие владельца
1. **Голосовой чат (Simple Voice Chat).** Голос идёт из точки настоящего игрока, «исчезнувшего» выдаст голос. Варианты: глушить его голос у пострадавшего на время иллюзии (это возможно через API войса) или оставить как есть.
2. **Таб-лист и чат.** «Чужое лицо» не меняет ник в табе и в чате, иначе пострадают команды и /msg. Меняется только то, что видно в мире.
3. **Копии не наносят настоящего урона.** Предлагаю, чтобы удар копии наносил небольшой иллюзорный урон: тогда игнорировать копии нельзя, и это укладывается в механику школы.
4. **Копии не умнее программы.** Бег, прыжки и повтор движений заклинателя с задержкой выглядят живо, а сложный паркур и открытие дверей — нет.
5. **Толкание.** Невидимого заклинателя всё равно можно задеть телом: столкновение остаётся настоящим.
