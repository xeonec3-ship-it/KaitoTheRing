# T24 «Стёртое имя»: план до кода (Кодинг → управляющему)

T22 сдан (`2026-11-19_Coding_T22.md`). По T24 ниже то, что реально сделать, и как. **Жду ответа по плану**,
как и с T22, после ответа начинаю.

## Исчезновение: что реально

**Главный приём:** сервер **не отправляет сущность стёртого другим клиентам**, как будто он вышел. Это mixin на отслеживание
сущностей: другим игрокам приходит «сущность удалена» и больше ничего о нём не приходит. Отсюда сразу, без отдельной работы:

- модели, брони, предметов в руках, тени и ника над головой нет;
- нет частиц и звуков, которые клиент строит от самой сущности (шаги, взмахи, шорох брони);
- нет точки на миникартах (JourneyMap, Xaero) и строки в Jade/WTHIT/TOP: клиенту нечего показать.

**Остаётся слышно:** звуки, которые сервер шлёт по координатам (удар по блоку, установка, взрыв, звук каста Iron's).
Это «по возможности» из ТЗ. Глушить все звуки мира в точке рядом с ним не буду: заглушит и других.

**Отдельно:**

| Что | Как |
|---|---|
| Tab | пакет «удалить из списка игроков» всем, кроме него. Тем, кто зайдёт позже, — сразу после входа |
| Сообщения чата | «*Ник* стёрт из мира» / «*Ник* вернулся в мир», жёлтым, всем и ему. Ванильные «покинул/зашёл» для стёртого гасятся (вход и выход во время стирания — без сообщений) |
| Сообщение о смерти | гасится. Стирание после смерти и возрождения остаётся |
| Его чат и /msg, /tell, /w, /me | не уходят никому; ему — «Тебя никто не слышит» |
| Голос (Simple Voice Chat) | его голос не слышен никому (тот же плагин, что в T22) |
| Мобы | не могут взять его в цель: смена цели отменяется, уже взявшие цель её теряют |
| Урон | его урон по всем ×0.25 |
| Лечение | любое лечение отменено (зелья, реген, естественное); тотем не срабатывает |
| Подбор предметов | запрещён |
| Чужие сундуки и приваты | работают **как обычно**: ТЗ читаю как «только своё, как обычно». Если имелся в виду полный запрет — скажите |
| Колдовство | можно |

## Сам стёртый

- Видит мир нормально, по краям экрана выцветание (накладка из письма визуала), тихий фоновый шум «пустоты».
- Руки полупрозрачные: попробую через рендер рук. Если с Epic Fight не выйдет, оставлю только накладку и сообщу.
- Срок хранится в данных игрока как время окончания по реальным часам. Перезаход и перезапуск сервера срок не сбрасывают.
  При входе он сразу скрыт.

## Снятие

- Через 10 минут — «вернулся в мир», эффект проявления, 10 с защиты от повторного стирания.
- «Благословение» снимает досрочно, с тем же сообщением.
- Команды оператора `/pohsmp erase clear <игрок>` и `/pohsmp erase list`. Добавлю ещё `/pohsmp erase set <игрок> <сек>`
  для теста: без него 15-секундный каст пришлось бы гонять каждый раз.

## Каст

- 15 с, LONG, сделан как «Падение» (Мироздание): свиток, без маны и ступени, откат 600 с, отдача Мироздания как у Downfall —
  если для этой ступени так принято.
- Цель — игрок, на которого смотришь, до 32 бл.
- Срыв без затрат: цель дальше 48 бл., вне прямой видимости дольше 2 с, или умерла.
- Себя стереть нельзя, уже стёртого тоже.
- Ролик: новая сцена в `Cutscene` по плану ТЗ (общий план → маг → распад цели → пустое место), видят все в 64 бл.
  Точные тайминги возьму из письма визуала. До письма — черновые, на 300 тиков.
- `scroll_erased_name` добавлю в ScrollModels, `erased_name` — в `Reg.CREATION_SPELLS`.

## Чего не будет

- Ник в списке команд и скорборде (FTB Teams, sidebar), если их выводит не ванильный Tab.
- Сообщения о достижениях — тоже гашу; если где-то ещё пролезает его имя, допишу по факту теста.
