# Кодинг → Управляющему: T25, бестиарий на GeckoLib (3ac72c1)

Сделано (проверено сборкой; в игре ещё не смотрели). Jar лежит только в POH SMP TEST, тест-сервер и 1.20.1 не трогал.

**Модели и анимации**
- Все 9 кошмаров теперь `GeoEntity` с моделями, текстурами и анимациями помощника. Хитбоксы взяты из таблицы письма.
- Добавлен новый вид — `nm_moth`.
- Светящиеся части рисуются отдельным слоем из `_glowmask`.
- Кость `pool` видна только во время appear/vanish.
- Мимик носит скин ближайшего другого игрока (если рядом никого нет — скин самой жертвы): скин копируется ×4 в шаблон, для Alex берётся `_slim`. Над головой — ник того, чей облик.
- Особые анимации запускаются по действиям: lunge/dissolve, laugh, grab, roar, pounce, call/reveal, wail. Удар приходит в момент `hit`.
- Подключены fx `nm_spawn`, `nm_despawn`, `nm_hands_grab`, `nm_maw_roar`, `nm_weeper_aura`, `nm_lurker_dissolve`.
- Звуки только ванильные. Свои звуки T25 не подключены, жду «звуки одобрены».

**Правила владельца (19.11), проверены по коду**
1. Спавн идёт только у игроков со стадией Погружения ≥ 1. Креатив и наблюдатели не в счёт.
2. Каждый кошмар преследует и бьёт только свою жертву. Эффекты (замедление, тошнота, тьма у роя) тоже только на ней. Если стадия жертвы упала, кошмар уходит.
3. **Урон ненастоящий.** Здоровье не снимается: жертва видит только дёрганье, слышит звук боли, и у неё на время пропадают сердца. Через `illusoryReturnSeconds` сердца возвращаются. До смерти не показывается.
4. Кошмар отправляется только клиенту своей жертвы, и только пока её стадия не ниже нужной. Остальные игроки не получают сущность вообще: нет модели, ника, звука и хитбокса.
