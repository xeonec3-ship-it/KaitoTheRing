# T06 «Темы печатей для школ Iron's» — доля управляющего готова

**От:** сессия управляющего (T06). **Кому:** управляющему и чату Кодинга. **Дата:** 19.11.

## Что сделано

Один генератор на всю тему — `python3 tools/gen_school_themes.py` (`--sheet` — ещё и лист-обзор). PowerShell-генератор
`tools/gen_school_sigils.ps1` перенесён в него и удалён (вместе с кругом-оберегом Восьми щитов `circle_ward`; путь в старом скрипте был сломан — `mods-src\…`).

Для каждой из 10 школ (Огонь, Лёд, Молния, Природа, Святая, Кровь, Край, Мистическая, Призывание, Ветер):

| Что | Файл |
|---|---|
| печать ступени **Высшая** под магом (5 слоёв: свечение, печать, лента мотивов, ядро, дуги), `hold: -1` | `sigils/<школа>_seal.json` |
| венец над головой для **Мифической/Божественной** (`sky`, 0.75 блока) | `sigils/<школа>_crown.json` |
| эффект каста Высшей: печать + вспышка + волна + частицы школы, `duration: -1` | `fx/school_<школа>_cast.json` |
| то же + венец на `caster+0,2.55,0` | `fx/school_<школа>_cast_crown.json` |
| стиль: палитра, частицы `@shards`, характер движения | `fx/styles/<стиль>.json` (кровь — `school_blood`) |
| текстуры 512: `<школа>_seal`, `<школа>_core`, `<школа>_crown`; лента `school_<школа>_band` 1024×128; частицы `mote_*` 128 | `textures/sigil/` |
| знак обычного каста перерисован на новых текстурах (id те же) | `sigils/school_<школа>.json`, `fx/school_<школа>.json`, `textures/fx/sigil_<школа>.png` |

Характер в рисунке: огонь — 36 языков пламени и алхимические треугольники, вихрь из трёх языков в ядре; лёд — сосульки,
снежинка с ветвящимися лучами, гранёные кристаллы; молния — разветвлённые разряды и зубчатое кольцо; природа — переплетённые
лозы с листьями, побеги с усиками, цветок с семенами по золотому углу; святая — лучи-клинья и два крыла из перьев;
кровь — вены, капли на нитях, терновое кольцо, полумесяц; край — тоннель портала, глаза Края, квадратики-частицы;
мистическая — щупальца с присосками, глаза, «живые» кривые кольца, око с ресницами; призывание — вихрь рун тремя рукавами,
клыки заклинателя, крылья векса; ветер — спиральные потоки с линиями тока, завитки, трискель.

Появление и распад у каждой школы свои: сборка по частям (`pieces`) у огня (12 вразброс), льда (6 по кругу, «иней»),
края (8 парами с полуоборота — «телепорт»), мистической (7 с кувырком) и у ленты рун призывания (10 по кругу); прорисовка
за 6 тиков с бешеным вращением — молния; рост с доворотом — природа и ветер (вихрь −320°); раскрытие из ребра — святая,
око мистической и края. Распад: `shatter` (огонь, лёд, ветер), увядание (природа), растворение в свете (святая),
стягивание (кровь, призывание), затягивание в портал (край). Таблица — `docs/sigils.md`, раздел «Темы школ Iron's (T06)».

Частицы на время каста: огонь — языки и искры вверх; лёд — льдинки и снежинки сверху; молния — искры + две молнии по земле;
природа — листья с покачиванием; святая — перья сверху + завеса лучей; кровь — капли вниз (`translucent`) + аура с пульсом;
край — плоская воронка из квадратиков; мистическая — 5 лент-щупалец по орбите; призывание — 3 следа рун по орбите; ветер — воронка-смерч.

## Что нужно от чата Кодинга

Сейчас по коду: `PohSpell.onCast` на **каждый** каст **заклинаний мода** (подклассов `PohSpell`) играет `fx/school_<школа>` —
эти id не менялись, новый вид подхватится сам. Двойной контур совместного каста (T15, HFx) берёт `textures/fx/sigil_<школа>.png` —
файлы те же, рисунок новый. **Запуска печатей ступеней нет** — ни для заклинаний Iron's, ни по ступени свитка. Нужно:

1. Подписка на начало каста (`SpellPreCastEvent` или трекер по тику, как `DivineEvents.onPlayerTick`) — для **любого** заклинания
   (в т. ч. собственных Iron's: fireball и т. п.), если у предмета каста есть ступень `Tier.of(stack)`:
   - `HIGHER` → `Fx.play(sl, Fx.fx("school_" + школа + "_cast").caster(sp).at(sp.position()))`;
   - `MYTHIC`, `DIVINE` → `"school_" + школа + "_cast_crown"`.
   Школа — `spell.getSchoolType().getId().getPath()`; список тот же, что `PohSpell.SIGIL_SCHOOLS`. **Ветер:** проверьте настоящий id
   школы Wind Spellbooks (я предполагаю путь `wind`).
2. Конец каста (каст завершён, отменён, прерван, logout) → `Fx.stop(sl, inst, "")` — печать распадётся по-своему.
   Мгновенные заклинания (время каста 0): играть с `.duration(40)` — постоят 2 с и распадутся сами.
3. Чтобы не было двух знаков: у заклинаний мода со ступенью не играть обычный `school_<школа>` из `PohSpell.onCast`.
4. По желанию для Божественной: `.color(Tier.DIVINE…)` не советую — перекрасит всю печать; лучше оставить цвет школы
   (золото Божественной уже даёт аура `DivineEvents`).
5. Проверка в игре: `/pohsmp sigil play fire_seal`, `/pohsmp sigil play fire_crown`, `/pohsmp fx play school_fire_cast_crown`
   и стоп; посмотреть частицы `lightning`/`vortex`/`ribbon`/`aura` у молнии, края, мистической, ветра и крови.
