## Что сделано

- **Каталог** `docs/sounds/catalog.md`: все 348 мест в коде, где магия играет ванильные `SoundEvents.*` (77 заклинаний/систем), по школам: заклинание → ступень → файл:строка, метод → роль (каст / нарастание / выпуск / раскрытие / цикл / удар / конец / отказ) → ванильный звук → наше событие. Пропущено 13 мест (Кошмары — уже свои; экипировка мантии — не магия).

Смысл звука сохранён: где был взрыв — наш взрыв в стиле школы, где звон — звон и т.д.
- **Звуки**: 292 событий, 671 файлов `.ogg` (моно, 44.1 кГц) в `assets/pohsmp_core/sounds/spell/<школа>/`, по 2 вариации (3 — у частых ударов и тиков). Все события — в `sounds.json` с `volume: 0.5` (владелец просил тише); субтитры ru/en в lang. Генератор — `tools/gen_spell_sounds.py` (повторяемый: те же имена → те же звуки).
- **Источники**: записи с OpenGameArt, обработаны (высота, реверс, реверберация, фильтры, кольцевая модуляция, слои) — `docs/sounds/sources.md`. По правилу владельца лицензии не проверялись; список — чтобы найти/заменить.
- **Демо**: `docs/sounds/review.json` (школа, заклинание, событие, файлы вариантов, что это, где звучит, что заменяет) и mp3-копии в `docs/sounds/mp3/` — для страницы владельцу.

## Как подключать (когда владелец одобрит)

1. Зарегистрировать события в `Reg.SOUNDS` (как `music.*`): `SoundEvent.createVariableRangeEvent(new ResourceLocation(MODID, "<событие>"))`. Удобно — циклом по списку из `docs/sounds/review.json` (поле `event`) в отдельном классе `SpellSounds` с `get("spell.explosion.hit_boom")`.
2. Заменить по таблице ниже. **Одно наше событие заменяет весь слой**: если в одном методе с одной ролью играют 2–3 ванильных звука (например `GENERIC_EXPLODE` + `WARDEN_SONIC_BOOM` + `BEACON_DEACTIVATE`), оставить ОДИН `playSound` с нашим событием, остальные удалить. Pitch — 1.0 (можно ±0.1 случайно): высота уже в файле. Громкость в коде — как была (база 0.5 — в sounds.json).
3. `getCastStartSound`/`getCastFinishSound` — вернуть наше событие. Школьные звуки каста в `Reg` (`DIVINE_POWER... () -> SoundEvents.X`) → `school.<школа>.cast`.
4. Заклинания без своих звуков (Безмолвный залп, Барьер, Безмолвные врата и др. — нет вызовов `SoundEvents`) не трогал; у каста Iron's для них играет звук школы — после регистрации это `school.<школа>.cast` (для своих школ).

## Что не успел / ограничения

- Звуки собраны **параметрически** (жест по смыслу + подпись школы + обработка), а не вручную по одному: на ~292 событий иначе не хватило бы времени. Вручную в редакторе ни один не слушал — нужна проверка на слух владельцем; что не понравится — переделаю точечно (у каждого события своё зерно, можно поменять записи/высоту).
- Длинных «под ролик» звуков (как у «Пробуждение не наступит») для ультимейтов не делал: каждое место — короткий звук (до 3 с). Для катсцен Божественных/Запретной/мифических можно собрать отдельные «stream»-дорожки по таймлайну — скажите, если нужно.
- Роли определены по имени метода и смыслу звука автоматически; в нескольких местах (тики со стадиями) одна роль покрывает разные стадии — при подключении можно развести.
- Строки в таблице — по коду на момент генерации; если Java поменяется, перегенерировать: `python3 tools/gen_spell_sounds.py --docs-only`.
