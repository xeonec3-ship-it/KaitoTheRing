# Проверка анимаций T26 (Глава Культа) и T30 (Эреб) на ошибки Арис/Мартина (помощник по визуалу → управляющему; для чата Кодинга)

Ветка `claude/cnpc-chats-repo-0hcody`. Java не трогал. Имена анимаций и времена событий (`timeline`) **не менялись** — ни одно.
Новое только у Эреба: добивание `ereb_finisher` (ваша добавка, раздел 5).

## 1. Как проверял
- **`tools/anim_check.py`** — покадровая проверка (шаг 0.05–0.1 с) всех анимаций обоих файлов. Анимации Iron's проверены те, что реально играют:
  - у Главы — удары и особые FireBoss: 7 комбо косой, `fire_boss_*`, `summon_fiery_daggers`, `offhand_parry`, `magma_throw`;
  - у обоих — касты из `SpellAnimations`.

  Как считает:
  - кинематика — как в GeckoLib 4 и превью;
  - предмет в руке — как у Iron's `HumanoidRenderer`: кость `bipedHandRight`, −1/16 z, −1/16 y, X −90°, затем `display.thirdperson_righthand`.

  Что ищет:
  - остриё позади босса в момент удара: события `timeline` и тики `AttackKeyframe` Iron's ±0.1 с;
  - оружие сквозь торс, голову, корону, ноги или в земле;
  - прокрутку оружия;
  - кисть за спиной;
  - ткань вперёд или сквозь ноги;
  - ключи через ±180°.
- **`tools/anim_check_render.py`** — кадры. Жёлтая стрелка — «вперёд», красная точка — остриё, синий брусок — жертва.
- **`tools/anim_check_sheets.py`** — листы «до / после»: `docs/media/t26_anim_check.jpg`, `docs/media/t30_anim_check.jpg`.
- Всё исправлено **в генераторах**, файлы анимаций пересобраны из них:
  - `gen_cult_leader_extra.py`, `gen_cult_leader_spells4.py`, `gen_ereb_anims.py`;
  - общий пост-проход — **`tools/anim_cloth.py`**: ткань и хват в анимациях Iron's.
- Проверено: пересборка без правок даёт тот же файл байт в байт. Изменились только перечисленные ниже анимации.

## 4. Чату Кодинга — Java (сам не трогал)
1. **Плащ Главы — знак (`CultLeaderModel.setCustomAnimations`)** — та же ошибка, что у Мартина.
   - Сейчас там `pushRotation(cape, 6° + swing·0.6)`. В осях GeckoLib для висящей кости **+X — вперёд**, а 6° назад уже заданы в модели (rotation 6 у кости `cape`).
   - Поэтому плащ в покое висит отвесно, а при ходьбе уходит вперёд в ноги.
   - Ошибка из моего прежнего письма: я дал знак в осях Bedrock.
   - Нужно: `transformStack.pushRotation(cape, -swing * 0.6f, 0, 0)` — без 6°.
2. **Полы Эреба (когда будете писать модель)** — формулы из письма T30 тоже в осях Bedrock. В `pushRotation` (оси GeckoLib) знак обратный:
   - задние: `coat_back_r rotX += min(0, rightLeg.getRotX()) · 0.4` — нога назад, rotX < 0, пола за ней назад;
   - передние: `coat_front_r rotX += max(0, rightLeg.getRotX()) · 0.55` — только вслед за ногой вперёд;
   - левые — так же по левой ноге.

   Это только для процедурной ходьбы. В наших `ereb_*` и в анимациях Iron's полы уже заданы ключами.
3. **Поза хвата косы (`CultLeaderModel`) — ОБЯЗАТЕЛЬНО**, иначе коса в покое лежит в земле, а в начале анимаций поза удвоится.
   - Сейчас: поза Iron's `(-30, -30, 10)` / `(-5, 0, -48)` с плавным `isAnimatingDampener`. Она держит лезвие на 4.2 px в земле.
     Кроме того, при выходе из анимации поза возвращается медленно (0.05·pt) — ~0.5 с коса ниже пола.
   - Теперь каждая анимация Главы (наши и Iron's в нашем файле) **сама начинается и кончается в позе хвата**. Поэтому:
     ```java
     boolean anim = entity.isAnimating();
     boss.isAnimatingDampener = anim ? 0 : 1;              // без плавного перехода: анимации сами входят в позу хвата и выходят из неё
     if (!anim && entity.getMainHandItem().is(CultLeader.SCYTHE.get())) {
         transformStack.pushRotation(arm, new Vector3f(25, -10, 15).mul(Mth.DEG_TO_RAD));    // = рука (−25, 10, 15) в осях анимаций
         transformStack.pushRotation(hand, new Vector3f(0, 5.5f, 96).mul(Mth.DEG_TO_RAD));  // = кисть (0, −5.5, 96)
         // + покачивание руки при ходьбе, как сейчас
     }
     ```
   - Вне анимаций коса «несётся» наискось вдоль тела, лезвие над плечом. Без этой правки в первые ~0.3 с каждой анимации поза хвата сложится дважды.
4. **События не менялись.**
   - «Огненный серп»: `throw` по-прежнему 1.0 с, `catch` 1.8 с; скрытие косы в руке на время полёта у вас уже есть (`CultFight`, main hand).
   - Добивание Главы: позиции жертвы — как в письме T26 (3.0 бл. впереди, подъём +2.3 бл. за 1.0–1.7 с); остриё теперь в ней.
