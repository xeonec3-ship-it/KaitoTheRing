# Управляющий → Кодингу (20.11): фиксированный каст у роликовых + что крафтится

Делать, когда владелец будет за ПК (он сам скажет). Ничего не менять без него.

## 1. Решение владельца: вся магия с камерой — фиксированной длительности
«Вся магия с камерой должна быть фиксированной по длительности». Сейчас характеристика Iron's «Сокращение времени каста»
(cast_time_reduction) укорачивает каст роликовых заклинаний (PohSpell.getEffectiveCastTime → super), а ролик камеры идёт по
константе CAST — заклинание срабатывает раньше конца ролика, всё разъезжается.
Сделать: у всех заклинаний, которые зовут `Cutscene.start`, `getEffectiveCastTime` = фиксированное время (как уже у SilentGate,
CovenArrival, Disintegration). Список по коду: DownfallSpell, MilkyWaySpell, SoulDevourSpell, TabooSpell, SpaceClosureSpell,
StarFallSpell, RiteSpell (Печать души, Благословение), ButterflyDreamSpell, ErasedNameSpell, NoAwakeningSpell, MythicT23 (Древо мира,
Око бездны, Последний рассвет). Удобно — флаг `fixedCast()` в PohSpell (по умолчанию false) и override true в этих классах;
`CastAnims.hideHands(…, getEffectiveCastTime…)` тогда сам станет верным.
Перезарядку (cooldown_reduction) — НЕ трогать, владелец не решал.

## 2. Крафт Высших и выше — по факту НЕ возможен (поправка управляющего)
Scroll Forge Iron's требует фокус школы. Теги фокусов `higher_focus`, `divine_focus`, `forbidden_focus`, `silent_focus` — **пустые**,
у `illusion_prism` и `broken_lullaby` нет рецепта. Поэтому заклинания школ Высшая/Божественная/Запретная (и Безмолвная) скрафтить
нельзя, даже если `allowCrafting()` = true (как у всех на HigherSpell). Кошмары и высшие Иллюзии — `allowCrafting` false (IllusionBase).
Если когда-нибудь в эти теги добавят предмет — сначала поставить `allowCrafting=false` у HigherSpell, иначе Высшие станут крафтиться.

## 3. Решение владельца (20.11): запрет крафта
«Запретим все заклинания Высшие, Миф, Божественные, Запретные, Безмолвные к крафту каким-либо образом».
- `allowCrafting()` = **false** для всех заклинаний ступеней HIGHER, MYTHIC, DIVINE, CREATION, UNKNOWN (по `Tier`: встроенная ступень
  из `Reg.*_SPELLS` и `DisintegrationSpell`) и для **всей школы Безмолвной** (в т.ч. 4 заклинания, которым 19.11 разрешали крафт без посоха —
  каст из свитков/книги остаётся, если свиток выдан; запрещён только крафт). Проще всего — один финальный `allowCrafting()` в PohSpell /
  HigherSpell / IllusionBase / SilentStaffSpell, который проверяет ступень и школу.
- «Каким-либо образом»: проверить и закрыть другие пути получения свитков этих заклинаний, кроме выдачи оператором/кодом мода —
  Scroll Forge, рецепты других модов (если в сборке есть что-то, что создаёт случайные свитки Iron's: торговцы, лут, сундуки —
  allowLooting уже false у всех наших).
- **Arcane Anvil — НЕ трогать** (владелец): прокачка обычных заклинаний выше максимума (например, фаербол до «Высшей») разрешена.
  Цель владельца — **наши** заклинания (из списков ступеней и Безмолвные) не должны попадать к игрокам без ведома админов.

## 4. Решение владельца (20.11): магия выше Высшей не записывается в книги и не вкладывается в предметы
Ступени MYTHIC, DIVINE, CREATION, UNKNOWN: запретить вписывание в книги заклинаний (Inscription Table Iron's: отменить вставку свитка
этой ступени в книгу — событие/миксин на слот, сообщение «Эта магия не поддаётся записи») и вкладывание в предметы (Arcane Anvil:
наделение оружия/брони/кольца заклинанием — imbue; любые другие ISpellContainer, кроме наших). **Исключение — наши посохи**
(SilentWitchStaff и staff(...) из Reg: higher/divine и т.п.) — в них эта магия остаётся. Высшую (HIGHER) это НЕ касается — её можно
в книги/предметы как раньше. Проверить, нет ли в сборке других модов с «контейнерами заклинаний» (книги/кольца/свитки-сборники).
