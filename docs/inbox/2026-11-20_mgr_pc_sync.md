# Задача для чата Кодинга (когда владелец за ПК): синхронизировать ПК и репозиторий — и держать их одинаковыми

Решение владельца 20.11: «когда я буду на ПК — обновить репозиторий и закинуть туда то, что есть на ПК, чтобы они всегда совпадали».

## Зачем
Код в репозитории `xeonec3-ship-it/KaitoTheRing` (ветка `claude/cnpc-chats-repo-0hcody`) частично восстановлен из истории чатов и может
отставать от ПК (`cnpc-project\mods-src\pohsmp_core`). Облачные помощники и программисты работают по репозиторию — если он отстаёт,
их правки ложатся на старый код и их приходится переносить вручную (см. `docs/HANDOFF_PC.md`).

## Порядок (делать один раз, по шагам, показывая владельцу разницу перед записью)
1. **Сначала забрать облачную работу на ПК.** В репозитории есть то, чего нет на ПК: боссы культа T26–T30 (`ru.pohsmp.core.boss.*`),
   фиксированный каст и запреты крафта/записи, визуал боссов, «Реплика», видео и т. д. Письма с перечнем — `docs/inbox/2026-11-20_cloudcode_*.md`,
   `docs/inbox/2026-11-20_mgr_*.md`. Тестовая сборка с этим кодом — `builds/pohsmp_core-1.16.0-bosses-test.jar`.
   - Скачать ветку во временную папку (`git clone -b claude/cnpc-chats-repo-0hcody https://github.com/xeonec3-ship-it/KaitoTheRing "%TEMP%\KaitoTheRing"`).
   - Сравнить с ПК **по файлам** (`git diff --no-index` или WinMerge): три группы — только на ПК, только в репозитории, есть в обоих и различаются.
2. **Решить по каждому различию** (владельцу — короткий список):
   - только в репозитории (новые файлы облака) → скопировать на ПК;
   - только на ПК → оставить, они уйдут в репозиторий на шаге 4;
   - есть в обоих и различаются → **ПК — главный** для старого кода; облачные правки в таких файлах перенести точечно по письмам
     («Точечные правки» в каждом письме). Ничего на ПК не перезаписывать целиком без показа разницы.
3. **Проверить на ПК:** `gradlew build`, тесты, запуск клиента и сервера; проверка тестового функционала по чек-листам писем
   (сначала на тестовом мире). Настоящий рабочий jar не заменять, пока владелец не скажет.
4. **Залить ПК в репозиторий:** сделать `mods-src\pohsmp_core` git-рабочей копией этой ветки (или скопировать содержимое ПК в клон),
   закоммитить состояние ПК целиком одним коммитом «Синхронизация с ПК <дата>» и запушить в `claude/cnpc-chats-repo-0hcody`.
   После этого репозиторий = ПК. Секреты и локальные файлы (`run/`, `.gradle/`, `build/`, логи, пароли) — не коммитить, проверить `.gitignore`.
5. **Записать итог** в `docs/inbox/<дата>_Coding_pc_sync.md`: что перенесено с облака на ПК, что ПК поменял в облачном коде, хэш коммита синхронизации.

## Как держать одинаковыми дальше (правило)
- **Каждое изменение на ПК** — коммит и push в `claude/cnpc-chats-repo-0hcody` в конце сессии чата Кодинга (а лучше после каждой задачи).
- **Перед началом работы на ПК** — `git pull` (забрать облачную работу).
- Облачные помощники всегда начинают с `git fetch` + merge и пишут, что поменяли, в письмах `docs/inbox/`.
- Сборки: настоящий jar — только по решению владельца; тестовые — с суффиксом (`*-test.jar`), рабочий не перезаписывать.
- Добавить это правило в `docs/inbox/README.md` (раздел «Синхронизация ПК ↔ репозиторий») после первой синхронизации.
