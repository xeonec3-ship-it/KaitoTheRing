## 2. Системные строки боя — на экран тем же свитком
Найдено и переведено все `sendSystemMessage` в `ru.pohsmp.core.boss.*` (5 вызовов):
- `ereb.vanish` «Эреб исчез. Бой окончен.» (финал Эреба, T30);
- `ereb_hand.vanish` «Эреб рассыпался бабочками. Бой окончен.» (ложная смерть Руки);
- `irina.mark` «%s — предмет ревности Ирины» (всем у арены);
- `irina.bond` «Нить связала вас с %s…» (каждому из пары).

Механизм: `BossCore.sysLine(who, key, args...)` → тот же `BossNet.SAY` (поле `c = BossSayMath.SYSTEM`, `s1` ключ, `s2` аргументы-строки
через `\u0001`, ≤250 симв.) → `BossSayClient`, та же очередь. Вид: нейтральный свиток `default`, **без имени и без нити**, текст прямой
(не курсив) холодный серо-белый `#D6D3CC`, по бокам первой строки — знаки босса, приглушённые до 55% (единственная подсказка, чей это бой),
без звука пера. `copyToChat` общий: при включении системная строка уходит в чат серым, без имени.
Action bar («выносит приговор…», «Пока метка на %s…» и т. п.) не трогал.

Тесты: `BossSayMathTest.systemArgsRoundTrip`, `systemLayout`. Макет: `tools/boss_say_preview.py sysline <старый_титр.png>`.
