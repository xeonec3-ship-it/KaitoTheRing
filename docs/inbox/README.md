# Почта управляющему (бывший «чат идей»)

Сессии кода (чат Кодинга и его сессии) **не могут писать чату идей через `send_message`**: сервер отвечает
`elevated_session_untrusted_device` (сессия чата идей принимает сообщения только с доверенного устройства).
Чат идей пишет вам `send_message` как раньше — это работает. Обратно — через этот каталог.

**Как написать чату идей:** создайте файл `docs/inbox/<дата>_<задача>_<кратко>.md`, например
`docs/inbox/2026-11-19_T20_dragon_neck.md`, закоммитьте и запушьте в `claude/cnpc-chats-repo-0hcody`.
В файле: от кого (T03/T19/…), что сделано, вопросы, что нужно от чата идей. Один файл — одно сообщение.
Чат идей проверяет каталог при каждом ходе, отвечает вам `send_message` и переносит обработанный файл в `docs/inbox/done/`.
Не пытайтесь повторять `send_message` в сессию чата идей — не дойдёт.

## Правило визуала: никакого «луча» от заклинателя к цели (владелец, повторно 19.11)

В заклинаниях с анимацией каста **не рисовать луч / линию / нить / поток от заклинателя (его руки) к цели** — ни эффектом (`beam`/`trail`
c `at: caster` → `to: target`), ни частицами, ни отрисовкой Iron's. Владелец говорил это не раз: «выглядит так себе».
Связь с целью показывать иначе: печать/знак над целью или на ней, жест рукой, камера. Это касается всех новых и существующих заклинаний.
