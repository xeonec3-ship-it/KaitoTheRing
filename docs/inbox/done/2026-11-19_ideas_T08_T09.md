# T08 + T09 — отклик печати на удар и распад трещинами (от: чат идей, сессия-помощник)

Ветка `claude/cnpc-chats-repo-0hcody`. Спеки: `docs/specs/tasks/T08_sigil_hit.md`, `T09_dissolve_cracks.md`.
Полное описание формата и формул — `docs/sigils.md`, разделы **«Отклик на удар (`hit`, T08)»** и **«Распад трещинами (`cracks`, T09)»**;
про купол — `docs/fx.md`, «Удар по структуре». Кадры: `docs/media/T08_sigil_hit.jpg`, `docs/media/T09_dissolve_cracks.jpg`.

## Что сделано

### 1. Формат JSON
- **`hit`** у печати: `{ duration, width, strength, rings, spacing, sheen, shake, shakePeriod, tilt, flash, sparks, sparkSpeed, color, max, cooldown }`;
  `"reactsToHits": true` / `"hit": true` / `{}` — со значениями по умолчанию (из спеки: волна за 8 тиков, дрожь ±2 %). `"hit": false` — выкл.
- **`dissolve.modes: ["cracks"]`** + блок `dissolve.cracks`: `{ count, rings, irregular, jag, crackTime, fallTime, gap, push, pop, fall, tumble, spin, glow, dust, color }`.
- Тот же `hit` понимает и файл меша (`fx/meshes/*.json`) — для ряби купола.
- Включено:
  - `hit`: `silent_barrier` (через `tools/gen_silent_outfit_fx.py`), `higher_blades`, `disintegration_field`, `forbidden_chains`, `coven_seal` (флаг
    `reactsToHits`), `taboo_ground` (через `tools/gen_mythic_fx.py`, у `sigil()` новый аргумент `hit=`), купол `meshes/silent_dome.json`
    (через `tools/gen_silent_staff_fx.py`). Это список из спеки (Дезинтеграция, Запрет, Табу, Ковен) + Тихий барьер + Высшая.
  - `cracks`: `higher_blades` (вместо `shatter`; 9 трещин, 1 кольцо = 18 осколков, 40 тиков).
- ⚠ `tools/gen_mythic_fx.py` при запуске затирает свежие ручные правки в `fx/ark.json` и `sigils/closure_emblem.json` (генератор отстал от
  файлов). Я их откатил и не трогал; если кто-то перезапустит генератор — проверить дифф.

### 2. Чистая логика (без Minecraft) + тесты
- `fx/sigil/SigilHit` — фронт волны, яркость в точке (`glow`), «лист» (`sheen`), волна по любой поверхности (`wave`, для купола),
  вздрагивание (`flinch`/`scale`), покачивание (`wobble`), искры (`spark`), слияние/лимит ударов (`accept`), «тело внутри печати → точка
  удара» (`contact`), сила из урона (`powerFromDamage`: 0.35 + 0.065·урон, с 10 урона — 1), общий хеш `hash`/`rnd`.
- `fx/sigil/SigilCracks` — углы трещин с изломом (`crackAngle`), кольца, бег трещин (`crackReach`, `ringCrack`), свет трещин, осколок
  (`shard`: отход, подскок, падение по миру, кувырок, поворот, альфа, вспышка при отрыве), очередь падения (`fallStart`: внешнее кольцо первым),
  пыль (`dust`), `shardAt`, `breaking`.
- `SigilDef`: записи `Hit`, `Cracks`, `DissolveMode.CRACKS`, `parseHit(JsonObject)` (общий для печатей и мешей), `reach()`.
  `SigilTimeline.layer`: при `cracks` слой после остановки не крутится и не гаснет (гаснут осколки).
- Тесты: `SigilHitTest` (12), `SigilCracksTest` (7) + старые — **36/36 зелёные**.
  ⚠ `./gradlew test` здесь не собирается: `Could not resolve all dependencies for configuration ':__obfuscated'` (нет доступа к Forge maven).
  Проверял так: `javac` пакета `fx.sigil` + тестов с gson 2.10 и JUnit 5 (console standalone 1.10.2) — все 36 прошли.
- Превью и Java считают **одинаково**: сверка 22 чисел (хеш, углы трещин, осколок, пыль, волна, вздрагивание, искра, покачивание, `shardAt`)
  Java ↔ JS — 0 расхождений.

### 3. Превью `tools/sigil_preview.html`
- Сцены: **«Отклик на урон»** (Высшая, земля), **«…: Тихий барьер»**, **«…: Дезинтеграция»**, **«…: купол Барьера»** — кнопки «Ударить»,
  «В центр», «Серия ×3», ползунок силы, авто-удары раз в 1.5 с; **щелчок по печати/куполу — удар в эту точку**.

### 4. Подключение в игру — **сделал сам, но не собрано и не проверено в игре** (нет Forge)
Проверено только: синтаксис и типы всего, что не зависит от Minecraft/Iron's (`javac` без классов игры — ошибок, кроме «нет символа», нет).
- **Сеть:** `FxMsg.HIT = 4` (точка x/y/z, сила в `scale`, `seed` int). `Net` протокол **7 → 8** (старый клиент с новым сервером не зайдёт — так и задумано).
- **Сервер:** `Fx.hit(level, inst, точка, сила)` — для заклинаний. `Fx.FxServerEvents.onHurt(LivingHurtEvent, LOWEST)` — сам находит
  экземпляры-печати с `hit`, в которых стоит раненый (по `SigilHit.contact`: ground — в радиусе и от −1 до +4 по высоте; sky — от +1 до −48;
  facing — ±max(1.5, R/2); billboard/outward — шар R+1), шлёт удар в проекцию середины тела. Раз в тик на экземпляр, не в первой половине
  появления, не во время разборки. В `Active` добавлены `stopped`, `attachOffset` (центр печати, привязанной к сущности), `lastHit`.
  Печати **внутри эффектов (fx)** сервер сам не проверяет (у них нет своего радиуса на сервере) — для них заклинание зовёт `Fx.hit` по эффекту;
  клиент раздаёт удар всем печатям и мешам эффекта, каждая печать берёт его, только если точка на ней (≤ 1.3 радиуса).
- **Клиент:** `FxClient` (op HIT → `SigilRun.hit` / `MeshDraw.Run.hit`, и для элементов эффекта), `SigilRun` (ожидающие и размещённые удары,
  передача детям), `SigilDraw`: `placeHits` (мир → плоскость), вздрагивание и покачивание базиса, `hits` (волна по слоям `disc/spokes/band` —
  их же текстура на полярной сетке 16×72 с альфой по вершинам; лист белой текстурой; вспышка; искры), `cracks` (осколки всех слоёв по общим
  трещинам — сетка квадов на осколок; светящиеся трещины через `FxDraw.glowStrip` плоско в плоскости; огоньки на кончиках; пыль). При
  `[fx] quality = low` — сетка реже, без искр и пыли. Буферы разных RenderType пишутся строго по очереди (immediate-источник закрывает
  предыдущий при взятии нового).
- **Купол Барьера (T20):** `MeshDraw` — рябь по брускам `boxes` (`SigilHit.wave` по углу на сфере), вздрагивание, вспышка и искры по нормали.
  `SageBarrierSpell.ripple` теперь при живом эффекте зовёт `Fx.hit(…, 0.85)` + звук вместо частиц-заглушки (частицы остались как запасной путь).

## Что проверить на ПК (основной чат)
1. `gradlew build` / `test` — компиляция `SigilDraw`, `MeshDraw`, `Fx`, `FxClient`, `FxMsg` (писал без сборки) и 36 тестов.
2. В игре: `/pohsmp sigil play higher_blades`, ударить моба внутри — волна, вздрагивание, искры; дождаться разборки — трещины, осколки.
   «Барьер» T20: выстрелить стрелой в купол — рябь по ячейкам. «Тихий барьер» T19 — удар по носителю.
3. Производительность: при нескольких ударах по большой печати (`disintegration_field`, радиус 4.5) — сетка 16×72 на слой, ~4 слоя;
   если тяжело, уменьшить `rings/sectors` в `SigilDraw.hits`.
4. Направление «вниз» у осколков земной печати — уходят в землю после подскока (так задумано: «осыпаются»); если некрасиво — уменьшить `fall` у печати.
