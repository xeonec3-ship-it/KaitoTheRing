Никогда не добавлять на посохи тонкую «антенну» сверху над навершием (шпиль, копьё, штырь над кольцом/камнем).

**Why:** владелец (2026-11-17): «Не добавляй никогда эту антену сверху на посохи, она плохо выглядит» — про верхнее копьё над кольцом посоха Низвержения.

**How to apply:** навершие заканчивается кольцом/камнем/рогами; в `tools/gen_school_staffs.ps1` не ставить вертикальных тонких деталей выше навершия. См. [[boss-rewards-chosen]] для прочих решений по предметам.
