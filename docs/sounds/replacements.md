# Замены «ванильный SoundEvents → наше событие» (для чата Кодинга)

Одно наше событие заменяет **все** ванильные звуки строки/места с той же ролью: если в методе играют 2–3 ванильных звука слоем (например `GENERIC_EXPLODE` + `WARDEN_SONIC_BOOM`), они заменяются ОДНИМ `playSound` с нашим событием (лишние вызовы удалить). Громкость/высоту в коде можно оставить как есть, но pitch ставить 1.0 (±0.1 для разнообразия): высота уже «зашита» в звук. Громкость 0.5 — в `sounds.json`.
