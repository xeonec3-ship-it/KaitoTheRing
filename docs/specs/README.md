# Задания для основного чата (код на ПК)

Здесь лежат задания, подготовленные в чате идей. Код по ним пишет основной чат Claude Code на ПК, в `cnpc-project`.
Перенос уже сделанной работы описан в [`../HANDOFF_PC.md`](../HANDOFF_PC.md).

| Задание | Что это | Статус |
|---|---|---|
| [`../HANDOFF_PC.md`](../HANDOFF_PC.md) | Перенос на ПК своих анимаций игрока для 5 заклинаний с роликом и скрытия предметов в руках | готово к переносу |
| [`sigils_spec.md`](sigils_spec.md) | Универсальные магические печати из JSON: формирование и разборка по слоям, дочерние печати, сеть, API для заклинаний и CNPC, превью-команды | не начато |
| [`fx_spec.md`](fx_spec.md) | Общая система нарисованных эффектов (лучи, волны, вспышки, перья, разрезы, молнии…) и стили школ; печать — один из её элементов | не начато, делать вместе с `sigils_spec.md` |

## Референсы

- [`../references/vfx_study.md`](../references/vfx_study.md) — разбор четырёх роликов с ультимативными заклинаниями. Это не задание,
  а копилка приёмов для своих идей, плюс решения по проекту: кто видит эффекты ролика, шейдеры не используются,
  ультимативная магия = заклинания с роликом камеры, темы печатей по школам, рост из поверхности только визуально.

## Идеи в обсуждении

- [`../ideas/coven_arrival.md`](../ideas/coven_arrival.md) — «Появление Ковена»: ролик 60 с, портал, выход заклинателя со свитой,
  реплика «Мы тоже примем участие, но для начала...», Закрытие Пространства на 15 минут. Концепт согласован, можно оформлять в задание.

## Порядок

1. Перенести анимации по `HANDOFF_PC.md` и проверить их в игре.
2. Печати и эффекты делать одной задачей: сначала общий каркас эффектов (временная шкала, загрузка JSON, стили, пакет, превью),
   затем печати как элемент `sigil`, затем остальные элементы по приоритету из `fx_spec.md`.

## Связь с анимациями игрока

- Референс у печатей тот же, что у анимации **Низвержения**: «God Wand», «Silent Gate». Разбор ролика, по которому сделана анимация, лежит в истории
  чата идей; тайминги анимации заданы в `tools/gen_player_anims.py` (`downfall_cast`).
- Эффекты «Активации» из того ролика ложатся на новые системы. Сфера-пузырь вокруг кастера — это `wave` (сфера).
  5–6 золотых кругов дугой за спиной — `onFormed` с `golden_halo`. Вспышка навершия — `flash` с привязкой к руке кастера.
  Анимация доходит до позы «Активация» к **4.4 с** каста, к этому моменту печать стоит сформировать.
- Висящий в воздухе посох в начале каста Низвержения (до 2.6 с) пока не сделан. Это кандидат в элемент `mesh` или отдельный клиентский эффект,
  с прятанием посоха в руке через тот же приём, что в `client/HiddenHands`.
