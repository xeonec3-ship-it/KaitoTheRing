# Дополнение к `sigils_spec.md`: общая система нарисованных эффектов (`pohsmp_core`)

Делать **вместе** с `sigils_spec.md`. Печати — это только один тип элемента. Нужна общая система красивых нарисованных эффектов для **заклинаний мода** (Божественная, Высшая и будущие школы). Отдельный API для CNPC под новые типы **не нужен** (у печатей он остаётся, как в `sigils_spec.md`).

## Идея архитектуры
- **Эффект** = композиция **элементов** на общей временной шкале (JSON, как печати): `assets/pohsmp_core/fx/<id>.json`. Элемент имеет `type`, `delay`, `duration`, привязку (точка / сущность / кость-рука кастера / направление взгляда / между двумя точками), цвет, яркость, easing появления и исчезновения.
- Заклинание вызывает эффект одной строкой из Java: `Fx.play(level, "id", ctx)` (ctx: кастер, цель, точки, направление, масштаб, seed) и может останавливать/обновлять (для канальных заклинаний).
- **Стили школ** (`assets/pohsmp_core/fx/styles/<school>.json`): палитра (основной, вторичный, ядро, тень), набор текстур по умолчанию (искры, руны, перья/осколки), режим смешивания. Элемент может ссылаться на цвет стиля (`"color": "@primary"`), чтобы один эффект перекрашивался под школу.
- Вся отрисовка — как у печатей: full-bright, аддитивно/полупрозрачно, без записи глубины, совместимо с Oculus, лимиты и качество в клиентском конфиге, отсечение по расстоянию.
- Команда превью для операторов: `/pohsmp fx play <id> [style]`, `/pohsmp fx reload`.

## Типы элементов
1. **`sigil`** — печать из `sigils_spec.md`.
2. **`beam`** — луч/столб света: от точки к точке, с неба вниз, из руки/посоха; толщина, ядро + ореол (2 слоя), прокрутка текстуры вдоль луча, рост от начала к концу, мерцание, сужение к концу; **ливень лучей** (`beam_rain`): N лучей со случайными точками в области, задержки, на месте удара — маленькая печать/вспышка.
3. **`wave`** — ударное кольцо по земле или в воздухе (расширяется, тает, может «следовать рельефу»), **сфера-пузырь** вокруг кастера (рост, прозрачный край, блик).
4. **`flash`** — вспышка: billboard-свечение в точке, «звёздный» блик с лучиками (anamorphic), опционально засветка экрана **у кастера** (короткая, мягкая, отключаемая в конфиге).
5. **`trail` / `ribbon`** — светящийся след за движущейся точкой (снаряд, оружие, рука), лента с затуханием по длине; **`slash`** — дуга-разрез от удара (толщина, изгиб, быстрый рост и угасание, вторичная тонкая дуга).
6. **`sprites`** — излучатель нарисованных частиц: **перья, лепестки, осколки стекла/кристаллов, звёзды-искры, пепел, руны-символы**; параметры: количество, разлёт, гравитация, вращение, кувыркание (для перьев — плавное покачивание при падении), затухание, размер по времени.
7. **`lightning`** — ветвящаяся молния/энергодуга между точками (перегенерация формы каждые N тиков).
8. **`vortex`** — спираль/воронка: вращающиеся ленты или спрайты, затягивание к центру или выброс.
9. **`chains`** — цепи/путы из нарисованных звеньев между точками (для Печати запрета, оков и т.п.).
10. **`aura`** — свечение-контур вокруг сущности (кастер на время каста, цель под эффектом), пульсирующее.
11. **`decal`** — рисунок на земле: трещины, выжженный след, светящиеся линии, медленно гаснет.
12. **`wings` / `halo`** — крылья света, нимб над головой кастера (2D-слои с покачиванием).
13. **`mesh`** — простые 3D-объекты из модели (кристалл, клинок света, колонна, врата): JSON-модель + анимация появления (рост, падение с неба, разлом на осколки). Сложные модели — позже, отдельной задачей.

## Стили школ (начальные)
- **Божественная:** золото и белый, тёплое ядро; перья, нимбы, столбы света, мягкие вспышки, медленное спокойное вращение.
- **Высшая:** алый и тёмно-багровый, белое ядро; острые осколки, резкие разрезы, трещины-декали, быстрые рваные движения.
- **Скалк (для эффектов, связанных со скалком):** тёмно-бирюзовый и чёрный; души-огоньки, звуковые кольца, щупальца-ленты, тусклое пульсирующее свечение.
Стиль задаётся файлом — новые школы добавляются без кода.

## Порядок работы
1. Каркас: временная шкала эффекта, загрузка JSON, стили, пакет S2C, превью-команды.
2. Элементы по приоритету: `beam`/`beam_rain`, `wave`, `flash`, `sprites` (перья/осколки), `trail`/`slash`, затем остальные.
3. Перевести эффекты Дезинтеграции и шести Высших заклинаний на систему (внешне не хуже текущих).
4. Демо-эффекты: «Ливень света» (Божественная: печать в небе + ливень лучей + перья + вспышки на земле), «Алый разрез» (Высшая: серия разрезов + осколки + трещины), «Пульс глубин» (скалк: звуковые кольца + огоньки).
5. Текстуры генерировать скриптами (`tools/`), свои, не копируя чужие ассеты.

## Проверка
- Каждый тип элемента — через `/pohsmp fx play`, со стилями всех трёх школ.
- FPS при нескольких тяжёлых эффектах одновременно; качество `low` заметно легче.
- С шейдерпаком (Oculus) и без; несколько игроков видят одно и то же.
