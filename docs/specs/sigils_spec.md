# Задание: система магических печатей (кругов) в `pohsmp_core`

Прочитай `README.md` мода (клиентская отрисовка `client/HigherFx`, пакет `HFx`, генераторы текстур `tools/gen_*.ps1`, `Core` API для CNPC). Перед сборкой копируй свежий `src` в `C:\Users\xeone\pohcore-build` и поднимай `mod_version`.

## Цель
Сейчас круги рисуются кодом под конкретные заклинания. Нужна **универсальная система печатей**: круг описывается файлом (JSON), а не кодом, и умеет **формироваться и разбираться** по слоям, как в референс-ролике (мод «God Wand», способность «Silent Gate»). Новые печати для заклинаний, боссов и ритуалов должны добавляться новым JSON и текстурой, без правки Java.

## Как печать формируется в референсе (то, что надо уметь)
- **Небесная печать:** сначала 3–4 **разорванные дуги** кружат вокруг центра и за ~1 с **смыкаются** в кольцо; затем изнутри наружу по очереди (шаг ~0.3 с) появляются слои: ядро → спиральное кольцо → кольцо рун → внешний обод; потом вся печать за ~1 с **вырастает** в несколько раз (ease-out). Соседние кольца вращаются в разные стороны с разной скоростью.
- **Земная печать:** под ногами кастера спирали проявляются с поворотом и затуханием-появлением, кольцо рун **прорисовывается дугой** (как пером, 0→360°).
- **Завершение формирования:** яркая волна по кругу + искры.
- **Дочерние печати:** после формирования главной — 5–6 маленьких золотых кругов раскрываются по дуге за спиной кастера на уровне груди/головы.
- **Разборка:** слои гаснут в обратном порядке, печать сжимается в точку (~1 с).

## Формат определения печати
Файлы: `assets/pohsmp_core/sigils/<id>.json` внутри jar (сервер тоже читает их из jar ради таймингов). Описать схему в `docs/sigils.md` с примерами.

Печать = список **слоёв** + общие параметры:
- `size` (радиус в блоках), `color` по умолчанию, `lifetime` (тики, или `-1` = пока не остановят), `hold` (сколько держать после формирования).
- `orientation` по умолчанию: `ground` (горизонтально, смотрит вверх), `sky` (горизонтально, смотрит вниз), `facing` (вертикально, по взгляду), `billboard` (всегда к камере).
- `onFormed`: список дочерних печатей (id, смещение относительно кастера/центра, расстановка по дуге: количество, радиус, угол, высота, задержка между ними).
- `formedFlash`: волна/искры при завершении (цвет, размер, длительность).
- `dissolve`: `reverse` (слои гаснут в обратном порядке), `collapse` (сжатие в точку), `fade`, `shatter` (разлёт дуг наружу) + длительность.

Каждый **слой**:
- `texture` (белая на прозрачном — цвет задаётся `color`, одна текстура на много цветов), `radius` (доля от `size`), `heightOffset` (смещение вдоль нормали, чтобы слои не мерцали друг в друге).
- `type`: `disc` (обычный квад с текстурой), `band` (полоса-лента, текстура повторяется по окружности N раз — для рун), `arcs` (N разорванных дуг заданной длины), `spokes` (лучи от центра).
- **Появление** (`appear`): `delay`, `duration`, `easing`, `mode`:
  - `grow` — масштаб 0→1;
  - `draw` — угловая прорисовка 0→360° (`startAngle`, направление);
  - `fade` — прозрачность 0→1;
  - `assemble` — для `arcs`: дуги стартуют дальше/с разными углами, вращаются и смыкаются в кольцо;
  - `unfold` — разворот из «ребром к камере» в плоскость.
  Режимы можно сочетать (например, `grow`+`fade`).
- `rotation`: скорость (°/с), направление, ускорение при формировании.
- `pulse`: пульсация яркости/масштаба (амплитуда, период).
- Ключевые кадры цвета/яркости по времени (опционально).
- Глобальный рост всей печати после формирования: `expand` (множитель, задержка, длительность, easing).

## Отрисовка (клиент)
- Яркая (full-bright), полупрозрачная/аддитивная, без записи глубины, двусторонняя; слои по `heightOffset`.
- Прорисовка `draw` — без шейдеров: рисовать круг как веер треугольников до текущего угла с правильными UV.
- Совместимость с **Oculus** (с шейдерпаком и без) — проверить стадию отрисовки (например, после полупрозрачного).
- Производительность: не рисовать дальше ~128 блоков (настройка), лимит активных печатей на клиенте, в конфиге клиента — качество (`low`: без дочерних искр/пульсаций).
- Существующие круги «Дезинтеграции» и `HigherFx` **перевести на новую систему**, внешне сохранив как есть (или лучше).

## Сеть и привязка
- Сервер шлёт пакет: старт (id определения, id экземпляра, позиция, ориентация, масштаб, цвет-override, длительность, seed), обновление (позиция/привязка), стоп (режим разборки).
- **Привязка:** к точке, к сущности (следует за кастером/целью со смещением), к взгляду сущности (`facing`).
- Отправлять игрокам в радиусе отслеживания; игрок, подошедший позже, получает активные печати (желательно).

## API
- Java (для заклинаний): `SigilFx.spawn(level, id, pos, orientation, scale, owner, duration)` → id экземпляра; `SigilFx.stop(level, instanceId, mode)`; колбэк на сервере «печать сформирована» (по таймингам из JSON) — чтобы заклинание могло стартовать удар ровно после формирования.
- **Для CNPC-скриптов** через существующий `Core`:
  - `Core.sigil(world.getMCLevel(), "id", x, y, z, "{json опций}")` → id экземпляра (опции: orientation, scale, color, duration, attachEntity UUID, offset);
  - `Core.sigilStop(world.getMCLevel(), instanceId, "collapse")`.
  Без вывода в чат.

## Команды для превью (только операторы)
- `/pohsmp sigil play <id> [scale] [orientation]` — проиграть печать перед собой.
- `/pohsmp sigil stop` — убрать свои.
- `/pohsmp sigil reload` — перечитать JSON без перезапуска (клиенту — по F3+T или пакетом).

## Текстуры
Расширить генератор (`tools/gen_*.ps1`): 512×512, белое на прозрачном, отдельными файлами: ядро, спиральное кольцо, лента рун (сегмент для `band`), внешний обод, тонкое кольцо, дуга, лучи-спицы, мягкое свечение. Руны — свои, не копировать чужие текстуры из референса.

## Демо-печати (сделать как примеры)
1. `silent_gate_sky` — небесная: дуги смыкаются → слои изнутри наружу → рост ×4 → разборка `collapse`.
2. `silent_gate_ground` — земная под кастером: спирали + прорисовка кольца рун + обод.
3. `golden_halo` — маленький золотой круг; вызывается дочерним по дуге (5–6 штук) за спиной кастера.
4. `disintegration_*` — перенесённые круги Дезинтеграции.

## Проверка
- Каждая демо-печать: формирование, вращение, вспышка, дочерние, разборка — выглядит как описано.
- Несколько игроков видят одно и то же; привязка к движущейся сущности.
- FPS с 10 печатями одновременно; без шейдеров и с шейдерпаком в Oculus.
- Вызов из CNPC-скрипта (`Core.sigil`), без текста в чате.
