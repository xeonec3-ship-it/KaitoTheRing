# Очередь задач (из чата идей, 19.11)

Каждая задача — отдельный файл, её можно отдать отдельной сессии основного чата. Задачи независимы, если не сказано иное.
**Исполнитель:** «осн.» — основной чат (нужна сборка и проверка в игре), «идеи» — делает чат идей (данные, генераторы, превью,
чистая логика с тестами); потом основной только подключает.

Правила для всех: ветка `claude/cnpc-chats-repo-0hcody`, перед работой `git pull`, при конфликте — слияние, не перезапись.
