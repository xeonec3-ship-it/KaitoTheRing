# T01. Скрытие сущностей и NPC

**Зачем.** CNPC-NPC не уважают невидимость при отрисовке, поэтому в «Появлении Ковена» свиту «в портале» прячут, поднимая на 150 блоков
над ареной. Это казус: NPC в другом месте, может упасть или загрузиться в другой чанк, вид ломается. Нужен общий способ спрятать любую сущность.

**Что сделать.**
1. Клиент: `client/HiddenEntities` — набор id сущностей. В `RenderLivingEvent.Pre` (и `RenderPlayerEvent.Pre`) отменять отрисовку:
   уходят модель, броня, предметы в руках, имя над головой (CNPC рисует имя в своём рендерере — проверить, что тоже уходит).
   Тень: на время скрытия ставить сущности ванильную невидимость с сервера (без частиц и иконки) — диспетчер не рисует тень у невидимых.
   Проверить: тень, огонь на сущности, частицы эффектов, хитбокс F3+B (оставить), `Glowing`-контур (отключить, если есть).
2. Сеть: пакет `Hide(entityId, ticks)` / `ticks = 0` — показать. Шлётся всем, кто отслеживает сущность; новым наблюдателям —
   при `PlayerEvent.StartTracking`. Срок истекает и на клиенте (на случай потерянного пакета).
3. Сервер: `Hidden.hide(entity, ticks, noDamage, noCollide)` / `Hidden.show(entity)`. Опции: отмена урона, без столкновений
   (`noPhysics` нельзя — сделать через `canBeCollidedWith`/толкание), NPC не двигается.
4. API для скриптов: `Core.hide(entity, ticks)` и `Core.show(entity)`; команда `/pohsmp hide <цели> <секунды>` и `/pohsmp show <цели>` (оп 2).
5. Ковен: свита «в портале» стоит на арене за порталом скрытой, вместо подъёма на 150 блоков.

**Готово, когда:** NPC CNPC, игрок и обычный моб полностью пропадают у всех наблюдателей (модель, имя, тень, предметы)
и появляются обратно; перезаход наблюдателя во время скрытия не показывает сущность; Ковен работает без подъёма свиты.
