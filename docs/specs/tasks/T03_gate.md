# T03. «Врата» по ролику Silent Gate (ультимативное)

Перенос заклинания из ролика (разбор — `docs/references/vfx_study.md`, раздел 5). Решения прошлых обсуждений в силе:
**без управляемой фазы** (решение 7), объёмные структуры генерируются скриптом (решение 9), свет — слоями без шейдеров.

**Последовательность** (каст ~15 с, ролик для всех в радиусе, как у других ультимативных):
1. 0–3 с — земная печать под заклинателем (`silent_gate_ground`), «туманность» за спиной.
2. 3–6 с — небесная печать над точкой удара (`silent_gate_sky` или сборка по частям), рост ×4.
3. 6–9 с — ядро печати разгорается в слепящую точку с горизонтальным бликом.
4. 9–12 с — **из света выходят огромные готические врата** (модель-`mesh`, окна-арки, крылья по бокам), падают перья, вниз бьют лучи.
5. 12–15 с — врата крупно, крылья двигаются, засветка в белое → **ливень лучей** по площади (радиус ~14): урон каждому лучу, вспышки и кольца на земле.
6. Финал — врата уходят вверх в печать, печать сжимается в точку.

**Делит работу:** чат идей — генератор модели врат (`tools/gen_gate_mesh.py` → `fx/meshes/silent_gate.json`, части с появлением «из света»),
эффект `fx/silent_gate.json`, анимация игрока, превью. Основной — заклинание (школа? Божественная по смыслу), урон, ролик камеры, отрисовка новых частей `mesh`.
**Открытый вопрос владельцу:** школа, ступень, урон лучей, кто может использовать.
