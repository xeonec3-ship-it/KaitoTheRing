# T05. «Падение звезды» (ультимативное, с роликом)

**Механика.** Каст ~8 с, точка взгляда до 48 блоков. Ролик: камера уходит в небо, видна падающая звезда со шлейфом, затем вид сбоку на удар.
Удар: урон по радиусу 8 (центр сильнее), отброс. Остаётся **кратер-декаль** и светящееся «стекло» на 30 с — только визуально, блоки не меняются
(решение 5 из `vfx_study.md`).

**Делит работу:** чат идей — эффект (`fx/star_fall.json`: печать-прицел на земле, звезда-`mesh` или спрайт с шлейфом, ударная волна, декаль кратера,
осколки), анимация игрока (руки к небу → резкий взмах вниз), превью. Основной — заклинание, ролик камеры (по образцу `DownfallCut`), урон.
**Открыто:** школа и ступень, урон.

**Эффект готов (сценарная часть).** `fx/star_fall.json` (генератор `tools/gen_higher_fx.py`) — заклинание берёт его само
(`StarFallSpell.FX`; временный `star_fall_temp.json` удалён в 1.15.0); шкала прежняя (ролик не трогать): 0–160 печать-прицел `star_fall_target`
собирается по частям, искры, волны, луч-наводка; 64 — звёздная печать `star_fall_sky` в `point:sky`; 96 вспышка звезды;
100–160 падение (шлейф алый + багровый + белое ядро, easeInCubic), мир краснеет; 160 удар (вспышка на экран, столб, сфера,
кольца, обломки, искры); до 760 — тёмная чаша, трещины, модель алого «стекла» `fx/meshes/star_glass.json` (растёт снизу),
тлеющие искры. Превью: сцены «Падение звезды», «Алое стекло (модель)».
