# T05. «Падение звезды» (ультимативное, с роликом)

**Механика.** Каст ~8 с, точка взгляда до 48 блоков. Ролик: камера уходит в небо, видна падающая звезда со шлейфом, затем вид сбоку на удар.
Удар: урон по радиусу 8 (центр сильнее), отброс. Остаётся **кратер-декаль** и светящееся «стекло» на 30 с — только визуально, блоки не меняются
(решение 5 из `vfx_study.md`).

**Делит работу:** чат идей — эффект (`fx/star_fall.json`: печать-прицел на земле, звезда-`mesh` или спрайт с шлейфом, ударная волна, декаль кратера,
осколки), анимация игрока (руки к небу → резкий взмах вниз), превью. Основной — заклинание, ролик камеры (по образцу `DownfallCut`), урон.
**Открыто:** школа и ступень, урон.
