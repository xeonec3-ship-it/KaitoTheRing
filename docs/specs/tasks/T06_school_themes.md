# T06. Темы печатей для школ Iron's

Для каждой школы Iron's (Огонь, Лёд, Молния, Природа, Святая, Кровь, Край, Мистическая, Призывание, Ветер из Wind Spellbooks) — стиль
`fx/styles/<школа>.json` (палитра, текстуры частиц, движение) и 1–2 печати `sigils/<школа>_*.json` со своими текстурами.
Применение: заклинания Iron's на ступенях Высшая/Мифическая/Божественная показывают печать своей школы под заклинателем на время каста.

**Чат идей:** текстуры (генератор), стили, печати, превью. **Основной:** подписка на начало/конец каста Iron's
(`SpellPreCastEvent`/`onCast`), запуск печати своей школы, если у свитка есть ступень.

**Решение владельца 19.11:** Божественная отличается от Мифической — `fx/school_<школа>_cast_divine.json`: печать + венец + дуга из 7 золотых
кругов (`golden_halo`) за спиной, раскрываются с краёв к центру, золотые блёстки. **Чату Кодинга:** в `SchoolSeals` — `DIVINE → "school_" + школа + "_cast_divine"`
(`MYTHIC` остаётся `_cast_crown`).
