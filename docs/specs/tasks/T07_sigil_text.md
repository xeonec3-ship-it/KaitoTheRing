# T07. Подписи-тексты на печатях

Новый тип слоя `text`: строка идёт по окружности (`radius`, `text`, `font`: `runic` / `latin` / `cyrillic`, `spacing`, `repeat`),
появляется режимом `draw` (буква за буквой). Строку можно подставить при запуске (`Core.sigil(..., '{"text":"..."}')`).

**Чат идей:** формат в `docs/sigils.md`, атлас символов (генератор текстуры с рунами и буквами), раскладка букв как чистая логика
(`SigilTimeline`/новый класс) с тестами, превью. **Основной:** отрисовка слоя по раскладке.
