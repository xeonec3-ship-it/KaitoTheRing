# T08. Отклик печати на урон

Если сущность внутри печати получает удар, по печати пробегает **волна**: кольцо яркости от точки удара к краю за 8 тиков,
плюс короткая дрожь (масштаб ±2 %). Для печатей с флагом `"reactsToHits": true` (Дезинтеграция, Печать запрета, Табу, Ковен).

**Чат идей:** формат, формула волны в `SigilTimeline` (яркость слоя в точке по расстоянию до фронта), тест, превью (клик = удар).
**Основной:** сервер ловит `LivingHurtEvent` у сущностей в печати → пакет «удар в точке» → клиент.

**Решения владельца 19.11:** распад трещинами (`cracks`) — только у Высшей (другим не включать). **Общий звук удара по печати — да:**
`sounds.json` → `pohsmp_core:sigil.hit` (хрустальный звон: chime аметиста ×2, удар по друзе, колокольчик нотного блока, резонанс — случайно один),
субтитр «Звон печати от удара». **Чату Кодинга:** зарегистрировать `SoundEvent` `sigil.hit`; играть в точке удара на сервере в `Fx.hit` и
в `FxServerEvents.onHurt` (громкость 0.5 + 0.5·сила, высота 0.9–1.15 случайно, не чаще 1 раза в 3 тика на печать); купол «Барьера» — этот же звук
вместо `AMETHYST_BLOCK_HIT`.
