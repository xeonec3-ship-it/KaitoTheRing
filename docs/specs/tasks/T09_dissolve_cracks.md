# T09. Разборка «трещины»

Новый режим разборки `cracks`: по печати пробегают трещины, она раскалывается на куски по линиям секторов (как у сборки `pieces`),
куски осыпаются вниз с поворотом и гаснут. Пара к сборке по частям.

**Чат идей:** формулы в `docs/sigils.md`, `SigilTimeline` + тест, превью. **Основной:** отрисовка (та же, что у `pieces`, плюс падение).
