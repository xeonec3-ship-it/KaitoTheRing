# T10. Свет под печатью и подсветка блоков

1. **Пятно света на земле** под небесной/висящей печатью: мягкий диск её цвета, проекция вниз на ближайшую поверхность, движется вместе с печатью.
2. **Подсветка блоков** вокруг большой печати: верхние грани блоков в радиусе подкрашиваются её цветом, к краю тускнеют.
   Без шейдеров: свой полупрозрачный аддитивный слой поверх граней (как декаль по рельефу) или временный световой уровень — выбрать, что дешевле.
Флаги в JSON печати: `"groundLight": {"radius":..., "strength":...}`, `"blockGlow": {...}`. Конфиг клиента `[fx] quality` low — отключать.
