# T12. Библиотека поз игрока (чат идей)

В `tools/gen_player_anims.py` — именованные позы и переходы: молитва, удар посохом о землю, руки в стороны, руки к небу, взмах-разрез,
толчок ладонями, поклон, стойка. Новое заклинание собирается списком «поза → время → плавность». В превью анимаций — список поз.
