# T13. Реакция цели

Пока цель держит Дезинтеграция/Реплика (и другие удерживающие заклинания), у **игрока-цели** своя анимация: руки скованы и разведены,
голова запрокинута, лёгкое парение. Для NPC CNPC — своя анимация CNPC или поза по событию.
**Чат идей:** анимация `pohsmp_held_target` (PlayerAnimator). **Основной:** запуск у цели при удержании, остановка при отпускании (у всех клиентов).

**Анимация готова (чат идей):** `pohsmp_held_target` (петля 4 с): за 0.8 с руки разводятся и скованы, голова запрокинута,
тело приподнято на 0.45 (парит), дальше — дрожь рук, покачивание головы и тела. Код: запуск у цели при удержании, остановка при отпускании.

**Код (1.15.0, основной):**
- Сервер — `spell/TargetPose`: `hold(цель)` / `release(цель)` со счётчиком (две удерживающие магии на одной цели — поза снимается,
  когда отпустят обе). Пакет — `HFx.ANIM` (a = id сущности, b = 1 старт / 2 стоп) всем, кто видит цель, и ей самой
  (`TRACKING_ENTITY_AND_SELF`); тот, кто подошёл или зашёл позже, получает старт при `StartTracking`.
- Дезинтеграция и Реплика: `hold` при захвате цели (`startHold`), `release` в `release(Hold)` — это все выходы: удар, отмена,
  смерть/исчезновение цели или заклинателя, страховка по времени.
- Клиент — `client/TargetPoseClient`: у игроков свой слой PlayerAnimator `pohsmp_core:target_pose` (приоритет 1500, выше слоя
  каста Iron's), вход/выход с плавностью 4/6 тиков; у прочих гуманоидов (NPC CNPC, зомби) — та же анимация на модели через
  `NpcCastClient.loop/stop`.
- Петля: `returnTick` = 16 (с 0.8 с, поза уже взята), дрожь и покачивание повторяются (`Anim.loop_from` в генераторе).
- Другие удерживающие заклинания подключаются двумя вызовами `TargetPose.hold/release`. «Застывший час» (FrozenHour) не подключён:
  там время стоит, поза «скован» не к месту.
