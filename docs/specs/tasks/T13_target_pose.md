# T13. Реакция цели

Пока цель держит Дезинтеграция/Реплика (и другие удерживающие заклинания), у **игрока-цели** своя анимация: руки скованы и разведены,
голова запрокинута, лёгкое парение. Для NPC CNPC — своя анимация CNPC или поза по событию.
**Чат идей:** анимация `pohsmp_held_target` (PlayerAnimator). **Основной:** запуск у цели при удержании, остановка при отпускании (у всех клиентов).

**Анимация готова (чат идей):** `pohsmp_held_target` (петля 4 с): за 0.8 с руки разводятся и скованы, голова запрокинута,
тело приподнято на 0.45 (парит), дальше — дрожь рук, покачивание головы и тела. Код: запуск у цели при удержании, остановка при отпускании.
