# T15. Совместный каст

Если рядом (до 6 блоков) второй маг кастует то же заклинание со свитком в течение первых 2 с каста первого — касты объединяются:
время каста ×0.7, у печатей двойной контур (второй слой со смещением и другим вращением), урон по правилам заклинания (не удваивать без решения).
Только для заклинаний с флагом «совместное» (список в конфиге). Второй свиток тратится тоже.
