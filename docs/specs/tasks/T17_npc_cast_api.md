# T17. API для NPC-магов

`Core.cast(npc, "pohsmp_core:disintegration", target)` — NPC CNPC (или любой моб) кастует заклинание мода (и Iron's) с анимацией,
эффектами и роликом, как игрок; `Core.cancelCast(npc)`; `Core.isCasting(npc)`. Цель — сущность или точка. Уважать правила заклинаний
(удержание цели, неотменяемость). Для босс-скриптов без сотен строк.
