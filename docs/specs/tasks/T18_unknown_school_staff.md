# T18. Школа и ступень «Неизвестная» + посох безмолвной ведьмы

Решение владельца 19.11: для «Врат» (T03) — новая школа **«Неизвестная»**, новая ступень **«Неизвестная»**,
кастуется **с посоха как в аниме** «Секреты безмолвной ведьмы».

## Школа (код — основной)

- `pohsmp_core:unknown`, название «Неизвестная» / «Unknown». Цвет `#7FFFD0` (бирюзово-зелёный, как магия ведьмы в аниме).
- Атрибуты `unknown_spell_power`, `unknown_magic_resist`; тип урона `unknown_magic` (в теге `bypasses_armor`); фокус школы — как у
  Божественной/Высшей. Звук школы — `minecraft:block.amethyst_block.chime` или тишина (безмолвная магия).
- Стиль эффектов `fx/styles/silent.json` (готовит чат идей).

## Ступень (код — основной)

- `Tier.UNKNOWN`: ключ `unknown`, «Неизвестная», цвет `#7FFFD0`, переливается (как Сотворение). Подпись в подсказке свитка/посоха.
- Свитков нет: заклинания ступени — только с посоха (как `CREATION_SPELLS` у Низвержения). Список `UNKNOWN_SPELLS = [silent_gate]`.

## Посох безмолвной ведьмы (модель — чат идей, код — основной)

- Предмет `pohsmp_core:silent_witch_staff`, «Посох безмолвной ведьмы». По образцу `DownfallStaff`: `AnimatedStaff` + `IPresetSpellContainer`,
  в слоте заранее «Врата» (заблокирован), каст с руки клавишей каста Iron's. Бонусы: +25 % к силе «Неизвестной» магии, +10 % к силе магии,
  +25 % к восстановлению маны.
- Вид по аниме: длинное тонкое **золотое** древко; навершие — **ажурная золотая рама** (лилия/трезубец): овальная петля сверху,
  изогнутые боковые завитки с листьями-остриями, мелкие шипы; в центре — **лиловый камень**; ниже рамы — **кольцо-колесо со светящейся
  бирюзовой сферой** (в аниме светится при касте); золотые кольца-перехваты на древке.
- Анимации GeckoLib: `idle` — сфера медленно пульсирует, камень мерцает; `cast` — сфера разгорается, кольцо крутится, вокруг навершия
  бирюзовые искры; `flash` — вспышка сферы.
- Файлы (готовит чат идей генератором `tools/gen_silent_staff.py`): `geo/item/silent_witch_staff.geo.json`,
  `animations/item/silent_witch_staff.animation.json`, `textures/item/silent_witch_staff.png` + `_glowmask.png`, `models/item/silent_witch_staff.json`.
- Комплект с одеждой ведьмы (T19) усиливает «Врата».
