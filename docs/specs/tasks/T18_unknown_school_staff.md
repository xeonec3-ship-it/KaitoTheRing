# T18. Школа «Безмолвная», ступень «Неизвестная» + посох безмолвной ведьмы

Решения владельца 19.11: новая школа **«Безмолвная»** (сначала называлась «Неизвестная» — переименована), новая ступень
**«Неизвестная»**; заклинания школы — **на посохе как в аниме** «Секреты безмолвной ведьмы».

## Школа (код — основной)

- `pohsmp_core:silent`, название «Безмолвная» / «Silent». Цвет `#7FFFD0` (бирюзово-зелёный, как магия ведьмы в аниме).
- Атрибуты `silent_spell_power`, `silent_magic_resist`; тип урона `silent_magic` (в теге `bypasses_armor`); фокус школы — как у
  Божественной/Высшей. Звук школы — `minecraft:block.amethyst_block.chime` или тишина (безмолвная магия).
- Стиль эффектов `fx/styles/silent.json` (готовит чат идей).

## Ступень (код — основной)

- `Tier.UNKNOWN`: ключ `unknown`, «Неизвестная», цвет `#7FFFD0`, переливается (как Сотворение). Подпись в подсказке свитка/посоха.
- Свитков нет: заклинания ступени — только с посоха (как `CREATION_SPELLS` у Низвержения).
  `UNKNOWN_SPELLS = [silent_gate, wind_spears, silent_volley, sage_barrier, worgan_flame]` (T20).

## Посох безмолвной ведьмы (модель — чат идей, код — основной)

- Предмет `pohsmp_core:silent_witch_staff`, «Посох безмолвной ведьмы». По образцу `DownfallStaff`: `AnimatedStaff` + `IPresetSpellContainer`,
  **5 заблокированных слотов**: «Врата» (T03), «Ветряные копья», «Безмолвный залп», «Барьер», «Чёрное пламя Ворганы» (T20);
  выбор колесом заклинаний Iron's, каст с руки клавишей каста Iron's. Четыре заклинания T20 работают **без комплекта**. Бонусы: +25 % к силе «Безмолвной» магии, +10 % к силе магии,
  +25 % к восстановлению маны.
- Вид по аниме: длинное тонкое **золотое** древко; навершие — **ажурная золотая рама** (лилия/трезубец): овальная петля сверху,
  изогнутые боковые завитки с листьями-остриями, мелкие шипы; в центре — **лиловый камень**; ниже рамы — **кольцо-колесо со светящейся
  бирюзовой сферой** (в аниме светится при касте); золотые кольца-перехваты на древке.
- **Части навершия колышутся, как в аниме** (решение владельца): подвески на цепочках качаются маятником с затуханием и отставанием
  по звеньям, боковые завитки и листья-острия чуть покачиваются, кольцо-колесо медленно поворачивается.
- Анимации GeckoLib: `idle` — колыхание частей, сфера медленно пульсирует, камень мерцает; `cast` — сфера разгорается, кольцо крутится, вокруг навершия
  бирюзовые искры; `flash` — вспышка сферы.
- Файлы (готовит чат идей генератором `tools/gen_silent_staff.py`): `geo/item/silent_witch_staff.geo.json`,
  `animations/item/silent_witch_staff.animation.json`, `textures/item/silent_witch_staff.png` + `_glowmask.png`, `models/item/silent_witch_staff.json`.
- «Врата» с посоха кастуются **только в полном комплекте одежды ведьмы** (T19); без него посох — обычный посох с бонусами.
