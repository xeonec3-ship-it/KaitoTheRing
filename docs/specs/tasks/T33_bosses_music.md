## Музыка по фазам
- Из каждого трека — **3 петли** по фазам: фаза 1 — вступительная/спокойная часть трека, фаза 2 — основная, фаза 3 — самая
  напряжённая (хор/кульминация; если в треке есть «вторая фаза» — она). Плюс **вступление** (не петля) — играет один раз на старте
  боя и переходит в петлю фазы 1.
- Петли — `.ogg` (Vorbis, 44.1 кГц, стерео, ~q5), стык петли без щелчка (резать по тактам, кроссфейд 20–50 мс в самой петле).
- Звуки: `pohsmp_core:music/<id>_intro`, `<id>_p1`, `<id>_p2`, `<id>_p3` (`stream: true`, категория `record`/`music` как у прочих
  `music.*` в `sounds.json`). Громкость выровнять между боссами (одинаковая громкость по LUFS, ~−16 LUFS).
- **Смена фазы:** кроссфейд 1.5 с с текущей петли на петлю новой фазы; смена — в момент вспышки полосы при переходе фазы.
- **Особые моменты:**
  - «Ложный рассвет» (Длань, 33%): музыка гаснет за 0.5 с, 4 с — короткий «победный» звук (уже есть), затем петля фазы 3 с удара
    волны (без кроссфейда — резко).
  - «Сон Бабочки: Полное Раскрытие» (Длань, 20%): петля фазы 3 с фильтром «как под водой»/реверберацией внутри сна (если просто —
    понижение высоких частот), снимается при пробуждении.
  - «Сон бабочки» первого Эреба (финал 5%): музыка затихает за 2 с.
  - Сдача (Арис, Мартин), уход Эреба, смерть Главы и Ирины: затухание 2 с.
  - Ролики особых (бой не замораживается): музыка не прерывается.
- Если петли фазы нет (не прислали/не нарезали) — играет петля предыдущей фазы; если трека нет совсем — заглушка Iron's, как сейчас.

## Кто что делает
- **Программист:** в каркасе (`BossCore.music`, `BossNet.MUSIC`, клиентский проигрыватель) — смена петли по фазам с кроссфейдом,
  вступление → петля, особые моменты выше, поздний зритель (startSeenByPlayer) получает текущую петлю с нужного места не важно —
  с начала петли. Ключи `[bosses_common]`: `music_crossfade_seconds = 1.5`, `music_fade_out_seconds = 2`.
- **Звукорежиссёр (облако):** когда владелец пришлёт файлы — нарезка на вступление и 3 петли по фазам, бесшовные петли, громкость,
  `sounds.json`, lang-субтитры; демо `docs/media/audio/<id>_phases.mp3` (все части подряд с кроссфейдами) для владельца.
