# Чек-лист проверки на тест-сервере (POH SMP TEST), 19.11

Как проверять: два игрока (А — заклинатель, Б — цель), оба в «POH SMP TEST», команды оператора доступны. Для каждого пункта — ✅ / ❌ + короткая
заметка или скриншот в `docs/inbox/<дата>_test_<что>.md`. Порядок — от простого к сложному.

## 0. Перед началом
- [ ] У обоих одна и та же сборка мода (F3 / список модов). В папке mods нет дублей Epic Fight (20.14.16 и 20.14.17) и двух CNPC-EpicFight-Addon.
- [ ] Серверный конфиг `[silent_gate] area = 120`.

## 1. Камера роликов (CamGuard) — для всех роликовых
- [ ] Каст любого роликового (напр. «Благословение») на холме / в лесу / у скалы: камера не уходит в блоки, не показывает пещеры изнутри.
- [ ] Отмена каста — камера плавно возвращается.

## 2. «Раскалённые угли» (3D)
- [ ] Холодный меч в руке объёмный, в инвентаре — плоская иконка.
- [ ] 5 попаданий → горящий меч (светится), ещё 5 → спецатака готова, спец → форма хлыста (в руке рукоять с раскалённым обрубком).
- [ ] Удары меча и хлыста разные; хлыст бьёт на дистанцию; корень хлыста — у обрубка.
- [ ] FPS с мечом в руках у обоих не проседает заметно.

## 3. Безмолвные врата
- [ ] Посох после оборота держится наискось у груди и виден в кадре «тсс»; камера в этот момент стоит.
- [ ] Круги в небе не пропадают при многих врагах; выстрелы по всей площади r≈120; звуков попадания нет.

## 4. Барьеры (обычный и Ковена)
- [ ] Моб, коснувшийся оболочки, гибнет; питомцы/свита внутри живы; босс — отталкивается.
- [ ] Внутри — нельзя Камень перемещения / свитки Waystones («Барьер не пускает»).
- [ ] Внутри чужого барьера можно Высшие/Мифические/Божественные/Мироздание, нельзя обычные.
- [ ] Вид: решётчатая стена; Млечный путь упирается в купол и оставляет трещины, которые затягиваются.

## 5. T21 «Печать души» / «Благословение»
- [ ] Печать: ролик, Б после — не может колдовать ничем, «Душа запечатана»; печать остаётся после смерти и перезахода.
- [ ] Благословение снимает печать и все дебаффы; вспышка в конце.

## 6. T22 «Иллюзии» (А колдует, Б смотрит; союзник — Shift+ПКМ Призмой)
- [ ] Отражения: копии неотличимы (ник, скин, броня, анимации EF), держат 2–3 удара, бьют иллюзорно; голос А идёт от копии.
- [ ] Ложный шаг: А пропадает у Б на 1.5 с, копия бежит дальше.
- [ ] Пелена, Фантомная боль (иллюзорный урон возвращается), Чужое лицо (облик другого игрока/моба).
- [ ] Лабиринт: зеркальные стены у Б, лево/право поменяны.
- [ ] Кошмар наяву: у Б все — чудовища; печать над Б видит только А.
- [ ] Сон бабочки: 2 мин, r64; у Б 3–5 копий-охотников, лево/право; урон по Б только на сердцах; «смерть» во сне → перенос; пробуждение — здоровье как было; музыка, кульминация на пробуждении.

## 7. T23 Мифические
- [ ] Древо мира: рост дерева, корни тянут, рубятся; цветение — споры.
- [ ] Око бездны: под открытым небом — урон и искажения; взгляд на Око — удар; под крышей — безопасно.
- [ ] Последний рассвет: союзники не умирают 12 с, потом лечатся.

## 8. T24 «Стёртое имя»
- [ ] В чате «Б стёрт из мира»; Б нет в Tab, в мире, на карте; его чат и голос никто не слышит.
- [ ] Б не может открыть ничего, ломать/ставить блоки, подбирать; урон ×0.25; не лечится.
- [ ] Перезаход Б не снимает; через 10 мин (или `/pohsmp erase set Б 20` для теста) — «Б вернулся в мир».

## 9. Свитки
- [ ] Свитки всех Высших/Божественных/Мифических, Иллюзий, Кошмаров, безмолвных — свои картинки.
